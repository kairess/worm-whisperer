## 1. 출발점과 목표
- 요청: OpenWorm으로 LLM 명령("왼쪽으로 가", "춤춰봐", "유튜브 보는중")에 반응하는 꼬마선충 시뮬레이터. 뉴런 구조를 유지하고 과학적으로 의미 있게.
- 확정된 원칙 (PLAN.md 1.1): 커넥톰 불변, LLM은 조종사가 아니라 실험자(화이트리스트 프로토콜만), 모든 프로토콜에 근거 논문, 재현 가능, 문헌값과 비교.
- 방향 결정: API 방식 대신 **학습형 번역기(옵션 B)** — 로컬 LLM 임베딩 → 뉴런 자극 패턴. 출력 채널을 감각·명령 뉴런으로 제한.
- 환경: uv, Intel Mac(JAX 0.4.38 고정), 2D 신체 모델로 확정, Sibernetic 제외.

## 2. 진행 순서와 핵심 발견 (시간순)

3. 지속 자극 ≥2 pA에서 전역 상향 상태(쌍안정). AVB는 예외.
4. **Phase 1b** Randi 2023 신호전파 아틀라스 비교: 동역학 모델 > 해부학(유의), 예측력은 갭정션 확산, 화학 시냅스는 휴지에서 꺼짐(Vth 0 mV), 억제 재현율 0. 상관은 측정 상한(ρ 0.14) 근접.

9. **Phase 4** 번역기(MiniLM 임베딩 → 프로토콜 혼합, ADR-014): 새 표현 0.84, 행동 축 일치 0.96. (09-03 개정 후 0.86 / 1.00)

12. 사용자 피드백: 좌/우 반대 → 규약 수정(배쪽 SMDV = 왼쪽). 코 터치 시 전진은 모델 한계(억제 부재)로 설명.

### Phase 3 개정: 유턴·춤·회전 강화 (ADR-016, RESULTS_PHASE3_4 1b)
- 진단: omega_turn 에서 RIV +55 / SMDV +51 mV 로 뉴런은 충분히 반응. 문제는 운동층 — 머리 편향(6 행)은 진행 방향을 못 바꾸고, 정적 배쪽 편향은 몸을 말지만 파동이 멈춤(+42° 최대).
- 채택: RIV ΔV > 30 mV 시 깊은 배쪽 굽힘 펄스(σ 4 행, 이득 0.36)가 머리→꼬리로 2.5 s 전파 (`Worm.k_omega`, Croll 1975/Broekmans 2016). omega_turn **+3° → +174°**, 전진 0.10 mm/s 유지. 문턱 30 mV 는 SMD 자극 시 갭정션으로 새는 RIV 상승(≈20 mV)을 걸러 다른 프로토콜 불변.
- 회전 시 1 Hz 문제: 편향 6 행 vs 수용기 6 행 이동 창의 불일치가 원인. 편향 12 행 + 이득 0.03 → 주파수 0.55–0.67 Hz, 회전 ±27° → +52°/−44°.
- local_search 재정의(기존 정의는 RIV 미사용): 후진 1 s → 오메가 2 s → 머리 흔들며 전진 3 s, 6 s 주기 → 12 s 에 +369°(피루엣 2회).
- 번역기: "유턴해/유턴/U턴" 이 forward 로 읽히던 문제 → 유턴 변형 7문장 추가(검증 0.834 → 0.858). 혼합 확률 0.45 가 RIV 진폭을 희석해 문턱을 못 넘는 문제 → 디코딩 선명화 p² (`predict(gamma=2)`, ADR-014 보완). 행동 평가: 프로토콜 일치 0.96 → 1.00, 축 일치 0.96 → 1.00, 최근접 0.65 → 0.81. 서버에서 "유턴해" → 150° 회전 확인.

## 3d. 2026-09-03 (같은 날, 이어서): 두 번째 프로젝트 Worm Gym 시작 — `docs/PLAN_WORMGYM.md`
- 방향: "이 뇌로 무엇까지 할 수 있는가". 번역기 자리에 학습 에이전트(행동 = 화이트리스트 자극)를 놓고, 가설 H1(회로 충분성) → H2(항법 전략 재발견) → H3(제약의 비용) → H4(과제→회로 지도). 판정 기준은 학습 전 고정.
- 만든 것: `worm/env/gym.py`(numpy 환경), `worm/env/batch.py`(GPU 배치 환경), `worm/body/motor_block.py`(운동층+막대 JAX 블록, `Worm.fast_motor`), `Worm.override`(상한 대조군용 운동층 직접 조종), `experiments/wormgym_h1.py`(CPU ES), `wormgym_es.py`(GPU ES), `wormgym_analyze.py`(사전 등록 지표).
- 교훈 두 개: (1) 멀티프로세스 JAX 는 워커당 스레드 1개로 제한해야 한다. (2) 농도 증가분만 보상하면 "정지" 가 국소 최적 — 생존 비용과 거리 벌점 추가.
- **H1 충족** (같은 날 밤): 명령·조향 채널만으로 2.5 mm 화학주성 도달률 0.81 (40 s, n=256; 무작위 0.04). 학습된 전략: 농도 하강 → 후진, 상승 → 전진 + 오메가 굽힘으로 맴돎. 세부·경위(보상 성형, 로그 관측, 커리큘럼)는 `docs/PLAN_WORMGYM.md` 5절.
- **H1a 성립** (감각 채널만은 무작위 수준: 0.109 vs 0.125, 1.5 mm). 커리큘럼 2단계 최종(100세대): 2.5 mm 40 s 도달률 **0.914** (n=256) — H1 최종 수치.
- **H2-2 풍향계 불성립** (조향 부호와 소스 쪽 일치율 0.27; 조향은 dC/dt 에 묶여 오메가 회전각 조절용). 설계 한계: 0.5 s 간격으로는 머리 흔들기 위상을 못 잡음 → 후속은 0.1 s 관측.
- **H3**: 학습된 직접 조종 정책은 정지에 갇혀 무효 → 오라클(소스 방향 아는 직접 조종기)로 대체. 도달률은 화이트리스트 정책이 오라클보다 높음(0.996 vs 0.676, 0.914 vs 0.895), 시간은 46–69 %. 도달률 기준 충족, 시간 기준은 정보 차이와 섞여 판정 보류.
- **H2-1** (AVB·AVA·RIV 만): 정책은 피루엣 규칙(하강 → 후진+오메가, 상승 → 전진)을 정확히 찾았으나(ρ −1.00) 도달률 0.11 로 항법 불가. 순수 run-and-tumble 은 이 모델에서 부족, SMD 조향 필요.
- 가설 요약: H1 ✓ (0.914), H1a ✓ (감각만 0.109 ≈ 무작위), H2-1 △ (규칙 ✓ / 능력 ✗), H2-2 ✗ (풍향계 아님; 0.5 s 관측의 설계 한계), H2-3 무효, H3 △ (도달률 ✓ / 시간 보류).
- 2026-09-04 **H4-1** 평지 절제: RIV 절제 0.914 → 0.066, AVA 0.098, SMD 둘 다 0.273 — "평지는 조향으로 충분" 예측 반증. 후진·오메가·조향 모두 필요. **H4-2** 머무르기 과제: 도달 0.93, 체류 0.33 이지만 RIS 사용 0 — 오메가로 맴돌아 머묾. 이동 비용 변형에서도 RIS 0, 대신 명령 드라이브를 낮춰 정지(예측 반증). Worm Gym 가설 판정표와 세 줄 결론은 `docs/PLAN_WORMGYM.md` 6절. **RIV 없이 재학습**: 2.5 mm 0.191 — 오메가 없이는 항법 불가. 결론: 최소 회로 = 후진 + 오메가 + 조향 (단 시간 감각만 주는 관측 설계에 조건부).

- 문헌: Qin & Wheeler 2007, Gourgou 2021 (T-미로 다감각 학습, DI 지표), eLife 2024 회전 통계(경계 근처 큰 회전 0.18 → 0.40), pH 회피의 후진/곡선 선택, Park 2008(기둥 밀기 추진; 우리 모델엔 없음).
- 만든 것: 막대 모델 벽 척력(`Rod2D(walls=…)`, 침투 0, 발산 없음)과 접촉 관측(`wall_touch`), 격자 셀 기반 미로 생성기(`worm/env/mazes.py`: L-통로, T-미로, 3×3), 배치 환경의 벽·접촉·시작/목표 옵션, 정책 확장(`fit_theta`), 미로 분석(`wormgym_maze_analyze.py`). 통로 폭 0.3 mm 에서 오메가턴이 물리적으로 막힘(H5-1).
- 결과 1: 평지 정책이 학습 없이 L-통로를 100 % 통과 — 후진이 아니라 "전진 + 오메가 드라이브가 벽에 눌려 벽 따라 미끄러지기" 기전 (H5-2 예측 반증, H5-4 벽 따라가기 창발). T-미로에서는 항상 배쪽(왼쪽)으로 꺾어 팔 선택이 우연(0.49). 3×3 격자는 0.
- 결과 2–4: RIV 절제 → T 교차점을 아예 못 꺾음(0/128); 상수 조향(SMDD/SMDV)만으로도 못 꺾음(0/32); 격자 미로(오른쪽 회전 2번 필요)는 학습 불가. **깊은 굽힘 방향 = 모퉁이 방향** — 굽힘을 등쪽으로 바꾼 가상 변형(DOMEGA)은 T-미로 도달 0.52 → 1.00, 팔 L/R 33/31. 문헌(Nature Neurosci 2026: SMDD/SMDV 가 등/배 방향, RIV 배쪽 편향; Gourgou 2021: 선천 편향 없음)과 합쳐 **ADR-017 후보**(펄스 방향 = SMDD−SMDV 부호, 화이트리스트 안) 제안. 검증 가능한 예측: 좁은 T-미로에서 팔 선택은 교차점의 굽힘 방향(등/배)이 결정하고, 등쪽 회전이 줄면 배쪽 팔 편향이 생긴다.
- 결과 5 (H5-3 A): 냄새+접촉으로 학습한 T-미로 정책은 도달 1.00·목표 팔 1.00 — 그러나 첫 진입은 여전히 64/64 왼쪽이고, 오른쪽 목표는 2 s 후진 발작 반복으로 팔을 거슬러 간다 (22 s vs 40 s). 실제 벌레(DI ≈ 0)와 구별하는 지표: 첫 진입 팔 편향, 목표별 도달 시간 차, 잘못된 팔에서의 후진.
- 결과 6: 오른쪽 회전 통로는 배쪽 굽힘 정책으로 0/32 (두 정책 모두) — 오른쪽 모퉁이는 원리상 불가. ADR-017 재학습 정책으로 재판정 예약 (`run_corridor_after_chain.sh`, 채택 조건: R-통로 ≥ 0.5).
- 결과 7 (H5-3 C): 접촉만 정책은 정지로 수렴, 도달 0. H5-3 순서 성립: 냄새+접촉 1.00 > 냄새만 0.49 > 접촉만 0.00 (Gourgou 2021 의 다감각 필요성과 부합; 단 "접촉" 의 기여가 관측인지 벽 물리인지는 관측 절제로 확인 중).
- 접촉 관측 절제: 냄새+접촉 정책은 접촉 입력을 0 으로 해도 도달 1.00·목표 팔 1.0, 오히려 빠름(29.8 s vs 40 s). 이 모델의 "다감각" 은 냄새 + 벽 물리이지 접촉 감각이 아니다. 냄새만 학습(`tmaze_odor_only`) 진행 중.
- ADR-017 재학습: 평지 2.5 mm 0.871(조건 1 충족), T-미로 도달 1.00·목표 팔 1.0 이지만 첫 진입은 여전히 128/128 왼쪽(교차점 방향 선택은 미학습). 프로토콜 검증: AVB+SMDD+RIV → −120° 오른쪽 유턴. **R-통로 학습 20세대 도달 0.94** — 배쪽 고정 규칙에서 불가능하던 오른쪽 모퉁이를 배움.
- **H5-6 판정**: 등쪽 굽힘이 가능해져도 학습은 "왼쪽 먼저 + 교정" 을 유지(시간 압력에서도 첫 진입 128/128 왼쪽, 교정만 32.5 s 로 빨라짐). 해석: 시간 이력 관측만으로는 교차점에서 두 팔을 구별할 수 없어 "들어가 보고 교정" 이 정보상 최선. 실제 벌레의 편향 없는 올바른 첫 선택은 좌우 기울기 표본(머리 흔들기 + 고유수용)이 있어야 한다는 예측 → **H5-7**: 머리 곡률(고유수용) 관측 추가 학습 예약 (`runs/wormgym/h5/proprio/`).
- **ADR-017 채택** (2026-09-05): R-통로 정책 최종 1.00 (같은 정책 L-통로 0.00 — 한손잡이). 규칙은 등쪽 굽힘을 가능하게 하고, 양방향 사용은 좌우 감각(H5-7)에 달림.
- **H5-8** (2026-09-05/06): 좌우 농도차 관측을 주면 평지 도달 0.988·중앙 16.5 s(오라클과 동속), 실현 굽힘 방향 = 소스 쪽 0.73 (등/배 양방향 사용; 정보 없으면 0.62). Nature Neurosci 2026 의 "기울기에 따른 등/배 선택" 재현. T-미로 첫 진입 판정 진행 중.
- H5-8 T-미로: 좌우 정보가 있어도 첫 진입 128/128 배쪽 팔. 미로 학습 없는 좌우 정보 정책은 교차점에서 등쪽 펄스를 80 % 정확히 쏘는데도 오른쪽 팔 진입 0 → 이 교차점에서 등쪽 굽힘이 기계적으로 실패. 오른쪽 벽 붙기(H5-9)·펄스 방향 고정(omega_lock) 모두 원인이 아님. 미해결 과제로 다음 회차에 이월.
- 마무리 (2026-09-05): 격자는 강건한 해 없음(최고 개체는 L/R 통로 모두 1.00 인 양손 정책이지만 시작 흔들기에 0.05). 고유수용 관측은 T-미로 26.5 s 로 최고 속도지만 첫 진입은 여전히 128/128 배쪽 팔(H5-7 불성립). H5 판정표와 핵심 주장 4개는 `docs/PLAN_WORMGYM.md` 8절.(평지 → T-미로 → 격자, `run_smddir_chain.sh`). 백그라운드 작업이 외부에서 반복 중단되어 nohup 으로 분리함 (중지: `pkill -f wormgym_es`).

## 3f. 2026-09-06: 논문 준비 — `docs/PAPER_OUTLINE.md` 개정 (주장 6개, 그림 6개, 투고 전 실험 E1–E5 사전 등록)
- E1 T 교차점 오른쪽 진입 실패 원인(프레임 기록 + 채널 절제), E2 학습 시드 반복, E3 통로 폭 민감도, E4 문헌 정량 비교(Pierce-Shimomura 1999 피루엣률, Gourgou 2021 DI), **E5 무작위 배선 대조군**(`Vfit-shuffle0`: 시냅스 표적·갭정션 뒤섞기, 가중치 보존). E5 가 논문의 핵심 문장을 정한다.
- 실행: `runs/wormgym/h5/run_paper_chain.sh` (nohup), 산출물 `runs/wormgym/paper/`.
- E1 해결: 오른쪽 팔 진입은 기계적으로 가능(x≈0.45 까지 진입). 벽 정체 → dlogC 약한 음수 → 평지 반사(후진 + 배쪽 굽힘) 발동 → 왼쪽으로 되돌아감. 제어 인공물이며 실제 벌레에 대한 예측("좁은 통로의 벽 정체가 피루엣을 촉발")으로 전환.
- E1 최종: 정체 중 "하강" 보고를 막으면(정체 게이트) 어느 팔에도 못 들어감(0.00) — "벽 정체 → 후진 + 배쪽 굽힘" 반사가 모퉁이 통과의 유일한 수단이자 오른쪽 진입 중단의 원인. 절제: SMDV 0.00 / AVA 0.50 / SMDD 1.00.
- E4a: 후진 개시율 대 dlogC/dt — 좌우 정보 정책 ρ −1.00 (0.126 → 0.001 /s), H1 정책 ρ −0.90; 부호·단조성은 Pierce-Shimomura 1999 와 일치, 기저율은 2–8배 높음.
