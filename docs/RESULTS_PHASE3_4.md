# Phase 3–5 결과: 프로토콜, 번역기, UI (2026-09-03)

코드: `worm/llm/protocols.py`(화이트리스트), `worm/llm/phrases.py`, `worm/llm/translator.py`, `worm/server/app.py`, `web/index.html`, `worm/env/chem.py`. 로그 `runs/phase3/`, `runs/phase4/`.

## 1. 회전(조향)과 정지 기전
- **조향**: Vfit 네트워크의 SMDD−SMDV 막전위 차이(ΔV)를 머리 6행의 선호 곡률 편향으로 잇는다 (Gray et al. 2005: SMD 가 머리 굽힘을 조향). 편향을 그대로 더하면 신장 수용기가 편향을 감지해 머리 단위가 한쪽에 고정되고 파동이 깨진다. Boyle 의 변형률 정의("국소 휴지 길이 기준")를 이용해 편향을 수용기의 기준 곡률로도 넘기면(수용기는 κ − κ_bias 만 감지) 파동을 유지한 채 몸이 휜다.
  - 실패한 대안: 정적 곡률 편향만 (등쪽 편향 시 정지), 머리 단위 문턱 편향 (파동 붕괴). `runs/phase3/steer_scan*.txt`
  - 채택 k_turn 0.06 (1/mm per mV): 왼쪽(SMDD) −26°/12 s, 오른쪽(SMDV) +27°/12 s, 기어가기 0.09–0.10 mm/s 유지.
- **정지(RIS)**: RIS ΔV 가 문턱(3 mV)을 넘고 명령/조향 뉴런 ΔV 의 1.5배보다 클 때 운동층을 끈다 (Turek et al. 2016 의 RIS 광활성화 → 즉시 정지). 이는 커넥톰 외 가정(펩타이드 FLP-11 효과)의 대체이며 플래그 `ris_gate` 로 분리. ALA 자극은 RIS 를 충분히 올리지 못해 정지시키지 못한다(정직한 부정 결과; Hill 2014 경로는 펩타이드 매개).

## 3. 번역기 (옵션 B-1, behavior cloning)
- 임베딩: `paraphrase-multilingual-MiniLM-L12-v2`(384-d, 고정). 대안 `multilingual-e5-small` 비교.
- 구조: MLP → (프로토콜 혼합 p ∈ Δ¹³, 진폭 배율 a) → u = a·Σ p_c u_c. 출력이 항상 화이트리스트 패턴의 볼록 결합이라 구조적으로 원칙을 지키고, 혼합으로 합성 명령을 표현한다.
- 데이터: 프로토콜당 한국어/영어 문장 20개(총 260). 문장 단위 분할(프로토콜당 5개 검증), 5개 시드.

| 임베딩 | 검증 정확도 (5 시드) |
|---|---|
| MiniLM (채택) | 0.837 ± 0.025 |
| e5-small | 0.809 ± 0.037 |

- 새 표현 예: "살살 앞으로 가줘"→forward 0.72, "왼쪽으로 살짝 틀어"→turn_left 0.84, "졸려"→quiescence_RIS 0.75, "뒤로 천천히"→reverse 0.89, "오른쪽으로 가면서 춤춰"→local_search 0.88 + turn_right 0.06 (혼합).
- **행동 수준 평가** (`runs/phase4/behavior_eval.txt`): 프로토콜당 검증 문장 2개(26개)를 번역기 → 스케줄 → 시뮬레이션(12 s) → 행동 기술자로 평가.

| 지표 | 값 |
|---|---|
| 예측 프로토콜 = 의도 | 0.96 (25/26) |
| 핵심 축(전진 부호, 회전 부호/크기) 일치 | 0.96 |
| 기술자 공간 최근접 프로토콜 = 의도 | 0.65 |

최근접 지표가 낮은 것은 번역기 오류가 아니라 프로토콜 자체가 행동적으로 겹치기 때문이다: quiescence_ALA 는 정지하지 못해 forward 와 같고, escape/터치는 모두 정지 상태이며, omega_turn 과 local_search 는 후진–전진 교대 패턴이 비슷하다. 유일한 번역 오류는 "뒤돌아" → reverse (의도 omega_turn).

## 4. 웹 UI (Phase 5)
`uv run uvicorn worm.server.app:app --port 8000` → http://localhost:8000. 채팅 입력 → 번역기 → 스케줄 → 50 ms 블록 시뮬레이션 → WebSocket 프레임(몸 좌표, 곡률, 근육 활성, 302뉴런 전압, 게이트, 상태 라벨과 근거). 실시간 배율 약 0.55 (Intel i7, 학습 병행 시 0.15).

## 5. S 등급 회전(화학주성)은 창발하지 않는다 (`runs/phase3/chemotaxis.txt`)
`worm/env/chem.py`: 가우시안 농도장, 머리 농도의 dC/dt 를 ASEL(증가)/ASER(감소) 전류로 (gain 50 pA per 농도/s, τ 0.5 s). AVB 전진 자극 병행, 20 s.

| 소스 위치 | 순 회전 | 소스 접근 거리 | 최대 ASE 전류 |
|---|---|---|---|
| 없음 | +9.1° | – | 0 |
| 왼쪽 (+y) | +9.5° | −1.49 mm (멀어짐) | 1.2 pA |
| 오른쪽 (−y) | +9.1° | −0.81 mm | 1.3 pA |
| 정면 (−x) | +9.0° | +3.06 mm (직진이라 접근) | 3.1 pA |

회전은 소스와 무관하다(모두 +9°, 무자극과 동일). 원인: (1) 0.18 mm/s 로 기어갈 때 농도 변화율이 작아 ASE 전류가 수 pA 이하, (2) Vfit 에서 ASE → SMD 경로의 이득이 조향에 미치지 못함(감각→명령 선택 실패와 같은 문제). 클리노택시스는 이 모델에서 재현되지 않으며, 회전 명령은 O 등급(SMD 직접 자극)으로만 성립한다.
