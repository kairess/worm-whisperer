# 설계 결정 기록 (ADR)

## ADR-001: 신체 모델은 2D 점탄성 막대, Sibernetic 미사용
- 날짜: 2026-09-02
- 상황: 실시간 대화형 제어가 필요. 개발 머신은 Intel Mac, GPU 없음. Sibernetic은 OpenCL 기반 3D SPH로 시뮬레이션 1초에 수십 분 소요.
- 결정: 24분절 2D 막대(Boyle 2012 계열)를 numpy/JAX로 구현. Sibernetic은 사용하지 않음.
- 결과: 실시간 가능, 미분 가능. 3D 효과(몸 비틀림, 유체)는 잃음. 벌레가 옆으로 누워 기어가므로 2D로도 좌/우 회전, 오메가턴 표현 가능.

## ADR-002: LLM은 화이트리스트 프로토콜만 선택
- 날짜: 2026-09-02
- 상황: LLM이 근육이나 운동뉴런을 직접 쓰면 커넥톰이 장식이 된다.
- 결정: LLM 출력은 `docs/COMMANDS.md`의 프로토콜 이름 + 파라미터로 제한. 스케줄러가 표 밖 뉴런을 거부.
- 결과: 모든 행동은 커넥톰을 통과해야 한다. 안 나오는 행동은 "안 나온다"고 기록하는 것이 과학적 결과.

## ADR-003: 신경펩타이드 층은 명시적 확장 모듈
- 날짜: 2026-09-02
- 상황: 정지 상태(RIS/ALA), roaming/dwelling(세로토닌/PDF)은 시냅스 커넥톰만으로 재현 불가.
- 결정: Bentley 2016 다층 커넥톰의 펩타이드/모노아민 층을 별도 모듈로 추가. 플래그로 on/off. 사용 시 UI에 배지 표시.
- 결과: "커넥톰 불변" 원칙과 충돌하지 않으면서 상태 행동을 다룰 수 있음.

## ADR-004: 신경 모델 파라미터 세트
- 날짜: 2026-09-02
- 결정: 개발과 실시간 데모는 c302 A/B, 검증과 결과 보고는 C2. Phase 1 속도 측정 후 재검토.

## ADR-005: LLM 연동은 학습형 번역기(옵션 B), API 방식은 부트스트랩 교사로만
- 날짜: 2026-09-02 (확정)
- 상황: API 방식은 명령→행동이 손으로 짠 표에 갇혀 학습 요소가 없음.
- 결정(안): 로컬 소형 LM의 고정 임베딩 → 자극 패턴 번역기를 학습. 출력 채널은 감각뉴런/검증된 명령 개재뉴런/펩타이드 층 스칼라로 제한(K≈25–30), 운동뉴런과 근육 제외. 프로토콜 표는 behavior cloning 교사 데이터로 사용.
- 전제: c302 A/B의 JAX 재구현으로 미분 가능한 시뮬레이터 확보. PLAN.md 7절.

## ADR-007: 신경 모델은 c302 C2를 JAX로 재구현, 파라미터 A/B는 사용하지 않음
- 날짜: 2026-09-02
- 상황: Phase 0에서 C2 전체 네트워크가 NEURON에서 안정적으로 실행되고(시뮬 1초당 8.6초), 명령 개재뉴런→운동뉴런 클래스 분화가 나옴. A/B는 c302 저자 스스로 "장기적으로 유용하지 않음"으로 평가.
- 결정: C2의 셀·시냅스·갭정션 방정식을 그대로 JAX로 옮긴다. c302가 생성한 NeuroML을 파싱해 연결 배열을 얻는다 (커넥톰 데이터 원천을 c302와 공유).
- 결과: 미분 가능, 배치 가능. NEURON 결과가 검증 기준으로 남는다.

## ADR-008: 실험은 항상 전체 302뉴런 네트워크로
- 날짜: 2026-09-02
- 상황: 명령 개재뉴런 + 운동뉴런 + 근육만의 부분회로는 자극 시 400 ms 안에 흥분성 역전전위로 폭주한다. 전체 네트워크는 폭주하지 않는다.
- 결정: 부분회로 실험은 하지 않는다. 속도 문제는 JAX로 푼다.

## ADR-009: 시간 간격 정책
- 날짜: 2026-09-02
- 상황: dt 수렴 연구(docs/RESULTS_PHASE1.md) 결과 오차가 dt에 비례. 0.25 ms에서 뉴런 RMS 0.08 mV, 실시간 이상.
- 결정: 탐색·학습은 dt 0.25 ms, float32 허용. 논문에 보고하는 수치는 dt 0.05 ms float64로 재확인. 두 값이 다르면 보고.

## ADR-010: 모델 변형은 명시적으로 번호를 붙여 관리
- 날짜: 2026-09-02
- 상황: c302 C2 기본 파라미터(V0)는 지속 감각 입력에 전역 상향 상태로 전이해 행동 실험이 불가.
- 결정: V0 기본, V1 Fenyves 2020 극성, V2 시냅스 전도도 스케일, V3 둘 다. 각 변형은 커넥톰(연결 존재/개수)을 바꾸지 않는다. 극성과 전도도는 "동역학 가정"으로 분류하고, Randi 2023 신호전파 아틀라스로 평가한다. 연결 자체를 바꾸는 변형은 만들지 않는다 (원칙 1).

## ADR-011: 작업 기준 신경 모델은 Vfit (V1-split + Phase 1c 적합 파라미터)
- 날짜: 2026-09-02
- 상황: V0 는 지속 자극에 폭주. Vfit 은 검증 세트에서 아틀라스 예측이 가장 좋고(AUROC 0.646, Spearman 0.131) 10 pA 까지 안정.
- 결정: 이후 행동 실험과 번역기 학습의 기본 신경 모델은 `make_variant(net, "Vfit")`. 단, Vfit 은 억제 시냅스가 사실상 제거된 모델이므로 억제가 중요한 현상(수면, 회피 전환)에는 별도 변형이 필요함을 명시한다.
- 커넥톰 불변 원칙 유지: 연결의 존재/개수는 바뀌지 않았고, 바뀐 것은 전역 전도도 배율과 시냅스 활성 곡선 파라미터 6개뿐.

## ADR-012: 운동층은 Boyle 2012 모델, 상류 회로는 커넥톰 (Vfit)
- 날짜: 2026-09-02
- 상황: c302 C2 세포 모델은 이력 없는 고이득 증폭기라 고유 진동이 없고(느린 K, Ca 활성 K, 채널 밀도 탐색 모두 실패), 고유수용 피드백만으로는 파동이 창발하지 않음. Gao 2018 의 A형 운동뉴런 진동은 주기 50 s 의 폭발 리듬으로 0.5 Hz 파동의 근거가 아님.
- 결정: 운동뉴런–근육 층을 Boyle, Berri & Cohen 2012 의 쌍안정 뉴런 + 신장 수용기 모델로 교체한다. 명령 개재뉴런(AVB/AVA)까지는 커넥톰 기반 Vfit 모델이 담당하고, AVB/AVA 막전위가 운동층을 게이트한다(전진: B형 후방 감지, 후진: A형 전방 감지 가정).
- 결과: 커넥톰 불변 원칙은 상류 회로에서 유지된다. 운동층은 "문헌 모델로 대체한 부분"임을 모든 결과에 명시한다. 운동뉴런 수준의 절제 실험은 이 층에서는 의미가 없다.

## ADR-013: 조향은 SMD 막전위 → 머리 곡률 편향 + 신장 수용기 기준 이동
- 날짜: 2026-09-03
- 상황: 정적 곡률 편향만 더하면 수용기가 편향을 감지해 파동이 깨짐(등쪽 편향에서 정지). 문턱 편향 방식도 파동 붕괴.
- 결정: 머리 6행 선호 곡률에 k_turn·(ΔV_SMDD − ΔV_SMDV) 를 더하고, 같은 값을 신장 수용기의 기준 곡률로 넘긴다(Boyle 의 "휴지 길이 기준 변형률" 해석). 규약: 배쪽(SMDV) = 왼쪽, 등쪽(SMDD) = 오른쪽.
- 결과: 12 s 에 ±26° 회전, 기어가기 유지. S 등급(화학주성)은 창발하지 않으므로 회전은 O 등급 프로토콜로만 제공.
- 보완 (2026-09-03, Ubuntu 세션): 편향을 머리 6 행에만 주면 수용기 창(6 행 이동 창)과 어긋나 단위 1–2 가 잔여 편향을 감지, 파동 주파수가 0.55 → 1.1–1.2 Hz 로 올랐다. 편향 범위를 앞쪽 12 행(SMD 돌기가 준측삭을 따라 몸 중간까지 뻗는 것에 해당)으로 넓히고 이득을 0.06 → 0.03 으로 줄이면 주파수 0.55–0.64 Hz 로 정상화되고 회전은 12 s 에 좌 +55°, 우 −49° 로 오히려 커진다 (`runs/phase3/turn_freq_scan.txt`, `turn_rows12_scan.txt`).

## ADR-014: 번역기는 프로토콜 혼합 헤드 (옵션 B-1)
- 날짜: 2026-09-03
- 상황: 임베딩 → (K×T) 자극 패턴 직접 회귀는 새 표현 정확도 0.60. 
- 결정: 임베딩 → 프로토콜 혼합 확률 + 진폭 배율 → 패턴의 볼록 결합. 출력이 구조적으로 화이트리스트 안에 머문다. MiniLM 다국어 임베딩 고정. 검증 정확도 0.84.
- 미완: B-2(시뮬레이터 루프 미세조정)는 Boyle 운동층이 불연속(쌍안정 스위치)이라 경사가 없다. 필요 시 무경사 최적화 또는 신경층까지만 미분.
- 보완 (2026-09-03, Ubuntu 세션): 디코딩 시 혼합 확률을 p^γ (γ = 2) 로 선명화한다 (`Translator.predict(gamma=2)`). 확신이 낮은 혼합(예: "유턴해" → omega_turn 0.45 + 나머지)이 펄스 진폭을 절반으로 희석해 문턱형 기전(ADR-016 의 RIV 30 mV)을 못 넘어 회전이 +32° 에 그쳤다. 선명화 후 0.82 → +149°. 두 프로토콜이 비슷한 진짜 혼합("뒤돌아": reverse 0.59/omega 0.40 → 0.68/0.32)은 비율이 유지된다. 학습은 바꾸지 않는다. 또한 omega_turn 학습 문장에 "유턴/U턴" 변형 7개 추가 (MiniLM 이 외래어 "유턴" 을 forward 근처로 임베딩하던 문제; 검증 정확도 0.834 → 0.858).

## ADR-015: 동역학 파라미터는 연결 클래스(세포 유형 쌍 × 부호)별로 둔다 (Phase 1d)
- 날짜: 2026-09-03
- 상황: 전역 파라미터 6개(Vfit)는 아틀라스 예측은 되지만 억제 응답과 감각→명령 방향 선택(Chalfie 1985)을 만들지 못했다(fit_D). 억제 시냅스에만 별도 동작점을 주는 θ8 탐색도 "모든 응답을 조금 음으로" 미는 퇴화 해만 냈다(RESULTS_PHASE1 7.2).
- 결정: 커넥톰과 세포 모델 구조는 그대로 두고, 파라미터를 NeuroML 의 세포 유형(sensory/interneuron/motor)으로 정의되는 **연결 클래스**별로 둔다. 화학 시냅스 18 클래스(pre 유형 × post 유형 × 흥분/억제)마다 log g, Vth, log δ; 갭정션 6 클래스(유형 비순서쌍)마다 log g; 누설 3 클래스. θ 63개. 근육 관련 연결은 c302 값 고정. 구현 `worm/neural/variants.py` (`connection_classes`, `apply_theta_class`), 적합 `experiments/phase1d_fit.py`.
- 이유: 세포별·시냅스별 자유 파라미터(수천 개)는 아틀라스 172개 자극으로 과적합되고 "커넥톰 불변" 원칙의 취지(연결 구조가 행동을 결정)를 흐린다. 유형 쌍 수준은 생물학적으로 해석 가능하고(예: 감각→개재 흥분, 개재↔운동 갭정션) 검증 세트(자극 뉴런 140개)로 일반화를 잴 수 있다.
- 손실: Phase 1c 손실 + 부호 균형 항(억제 쌍 ΔV>0, 흥분 쌍 ΔV<0 페널티) + Chalfie 힌지(PLM: AVB−AVA ≥ 2 mV, ALM+AVM: AVA−AVB ≥ 2 mV) + 초기값 능형 페널티.
- 한계: 아틀라스 억제 쌍의 83% 는 커넥톰 시냅스 경로가 없어(RESULTS_PHASE1 7.1) 어떤 시냅스 파라미터로도 재현되지 않는다. 억제 재현의 목표는 경로가 있는 26쌍으로 한정한다.

## ADR-016: 오메가턴은 RIV 활성 → 머리에서 꼬리로 전파하는 깊은 배쪽 굽힘 펄스
- 날짜: 2026-09-03
- 상황: omega_turn 프로토콜(AVA 2 s → AVB+SMDV+RIV 2 s → AVB)에서 RIV 는 +55 mV, SMDV 는 +51 mV 로 강하게 반응하지만 순 회전은 +3° 였다. 머리 편향(ADR-013)은 머리만 말고 몸의 진행 방향을 못 바꾼다. 앞쪽 절반에 정적 배쪽 편향을 주면 κ −7 /mm 로 말리지만 파동이 멈추고 벌레가 말린 몸을 따라 빠져나오지 못한다 (최대 +42°, 속도 0.056 mm/s; `runs/phase3/omega_scan.txt`).
- 결정: RIV 막전위 상승(ΔV_RIV > 30 mV, 직접 자극 수준)이 시작되면 배쪽 곡률 편향 펄스(가우시안, σ 4 행, 진폭 −k_omega·(ΔV_RIV − 30), k_omega 0.36)를 머리에서 꼬리로 2.5 s 에 걸쳐 이동시킨다. 선호 곡률과 신장 수용기 기준에 같은 편향을 준다(ADR-013 과 동일 원리). 문헌: Gray, Hill, Bargmann 2005 (RIV/SMDV 절제 시 오메가턴 감소; RIV 는 배쪽 목 근육 지배), Croll 1975 / Broekmans et al. 2016 (오메가턴 = 머리에서 꼬리로 전파하는 깊은 배쪽 굽힘). 커넥톰 밖의 운동층 가정이므로 `Worm.k_omega` 플래그로 분리하고 모든 결과에 명시한다.
- 결과: 유턴 구간 2 s 에 +162° 재정향, 전진 0.139 mm/s 와 파동 0.62 Hz 유지 (`runs/phase3/omega_scan_thresh30.txt`). 문턱 30 mV 는 SMD 자극 시 갭정션으로 새는 RIV 상승(≈ 20 mV)을 걸러 좌/우 회전·머리 흔들기·RIS 정지에 영향을 주지 않는다 (`protocols_omega_check.txt` 에서 문턱 10 mV 일 때의 누설 확인). local_search(춤)는 이 채널을 쓰도록 재정의 (후진 1 s → 오메가 2 s → 전진하며 머리 좌우 3 s, 6 s 주기).
- 한계: 펄스의 전파 시간·폭·이득은 문헌값이 아니라 탐색으로 정한 값이다. 이득 0.45 이상이면 과회전(−148°) 후 파동이 깨진다. 오메가턴은 항상 배쪽(왼쪽 규약)이다 — 실제 벌레와 같다.

## ADR-017: 깊은 굽힘 펄스의 방향은 SMDD−SMDV 가 정하고 RIV 는 진폭·배쪽 기본값 (2026-09-05 채택)
- 날짜: 2026-09-04
- 상황: ADR-016 은 오메가 펄스를 RIV 단독·배쪽 고정으로 두었다. Worm Gym 미로 실험에서 좁은 통로(0.3 mm)의 모퉁이는 깊은 굽힘이 벽에 눌릴 때만 돌아가고, 굽힘이 배쪽뿐이라 T-미로에서 항상 왼쪽 팔로 갔다(64/64). 실제 벌레는 T-미로에서 선천적 편향이 없고(Gourgou 2021), Nature Neurosci 2026("Neural sequences underlying directed turning")은 SMD 가 오메가 진폭, RIV 가 배쪽 편향, SMDD/SMDV 가 등/배 방향을 담당하며 벌레가 기울기에 따라 등/배를 고른다고 보고한다.
- 결정(후보): `omega_smd_dir=True` 이면 펄스 방향 = sign(ΔV_SMDD − ΔV_SMDV) (차 > 10 mV 이면 등쪽 κ>0, 아니면 배쪽 기본). 화이트리스트 자극 RIV + SMDD 로 등쪽 깊은 굽힘이 가능해진다. 가상 채널 DOMEGA(뉴런 아님)는 기전 확인용 대조군으로만 쓴다.
- 근거 실험: 평지 정책의 펄스를 등쪽으로 바꾸면 T-미로 도달 0.52 → 1.00, 팔 L/R 33/31 (`runs/wormgym/h5/dorsal_swap_test`). 규칙을 켜면 옛 정책은 모든 펄스가 등쪽이 되어 64/64 오른쪽 (`smd_dir_test`).
- 채택 조건과 결과 (2026-09-05): (1) 규칙 아래 재학습한 평지 정책 2.5 mm 도달률 0.871 (≥ 0.8 ✓), (2) 오른쪽 회전 통로 학습 도달률 1.00 (배쪽 고정 규칙에서는 어떤 정책도 0/32; ≥ 0.5 ✓), (3) 기본값 False 에서 첫 프로젝트 프로토콜·테스트 21개 불변 ✓. 프로토콜 수준: AVB+SMDD+RIV → −120° 오른쪽 유턴, AVB+SMDV+RIV → +171° (기존과 같음).
- 단서: 규칙은 등쪽 깊은 굽힘을 가능하게 할 뿐이다. 학습된 정책은 한손잡이(오른쪽을 배우면 왼쪽 0.00)이며, 상황에 따른 양방향 사용은 좌우 기울기 감각(고유수용 + 머리 흔들기, PLAN_WORMGYM H5-7)이 있어야 한다. 기본값은 False 로 두고(첫 프로젝트 재현성), Worm Gym 실험은 `omega_smd_dir=True` 를 쓴다.
