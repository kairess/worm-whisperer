# Phase 2 신체 모델 사양 (초안, 2026-09-02)

목표: 95개 체벽근 활성(신경 모델 출력)을 받아 한천 위 2D 이동을 실시간으로 계산하고, 곡률을 고유수용 입력으로 되돌린다.
근거 문헌: Boyle, Berri & Cohen 2012 (Front Comput Neurosci), Izquierdo & Beer 2018 (Phil Trans B), Gray & Lissmann 1964 (저항력), Wen et al. 2012 (고유수용).

## 1. 기하와 좌표
- 체장 L = 1.0 mm, 24 분절 (c302 근육 행과 1:1), 분절 길이 ℓ = L/24. 벌레는 옆으로 누워 있으므로 등/배 축이 평면 내 법선 방향.
- 상태: 각 분절 경계점 위치 r_k (k = 0..24), 분절 방향각 φ_k. 곡률 κ_k = (φ_{k+1} − φ_k)/ℓ (등쪽 굽힘을 +로 정의).
- 반지름 프로파일: r(s) = R₀·(1 − ((s − L/2)/(L/2))²)^{1/2} 형태(Boyle 2012), R₀ = 40 µm. 근육 모멘트 팔 = r(s).

## 2. 근육 → 토크
- c302 근육: MDL01–24, MDR01–24 (등), MVL01–23, MVR01–24 (배). 행 k 의 등쪽 활성 A_D,k = 평균(MDLk, MDRk), 배쪽 A_V,k = 평균(MVLk, MVRk) (MVL24 없음 → MVR24 만).
- 근육 활성 변수: 신경 모델의 근육 세포 막전위 V_m (mV) 또는 칼슘 농도 [Ca]_m 를 sigmoid 로 정규화. 1차 선택: [Ca]_m (c302 muscle CaPool 이 이미 근육 칼슘 동역학, τ 60.8 ms 를 가짐). A = [Ca]/([Ca] + K_half). K_half 는 Phase 0 무자극 대조군의 [Ca] 분포로 결정.
- 분절 k 의 능동 모멘트: M_k = M_max·r_k·(A_D,k − A_V,k). 등/배 길항.
- 수동 특성: 굽힘 강성 EI·κ, 점성 감쇠 η·dκ/dt. (Boyle 2012 값 참조: 큐티클 강성은 반지름에 비례해 스케일)

## 3. 환경 저항 (저항력 이론)
- 분절 속도의 접선/법선 성분에 비례하는 항력: F_t = −C_t·v_t, F_n = −C_n·v_n.
- 한천 기어가기: C_n/C_t ≈ 40 (Boyle 2012 의 agar 값), 수영: ≈ 1.5. 이 비가 보행(gait) 전환의 핵심 변수이며 `swim` 프로토콜에서 바꾼다.
- 관성 무시 (저 레이놀즈). 매 스텝 힘 평형: 근육 모멘트 + 탄성 + 감쇠 + 항력 = 0 을 분절 각도에 대한 선형계로 풀거나(암시적), 과감쇠 1차 동역학으로 명시적 적분 (dt 0.5 ms).

## 4. 고유수용 피드백 (실험 변수, 기본 OFF)
- Wen 2012: B형 운동뉴런은 앞쪽 분절의 굽힘을 감지해 같은 방향 굽힘을 전파한다. 구현: DB_k / VB_k 에 전류 I = g_p·max(0, ±κ_{k−1}) 주입 (등쪽 굽힘 → DB, 배쪽 → VB).
- 이는 감각 입력 추가이며 커넥톰 변경이 아니다 (원칙 1). ON/OFF 와 g_p 를 실험 변수로 두고 파동 창발 여부를 비교한다.

## 5. 검증 지표 (`docs/VALIDATION.md` 에 채움)
| 지표 | 문헌값 (한천 기어가기) |
|---|---|
| 파동 주파수 | 0.3–0.5 Hz |
| 파장 | 0.65–1.0 체장 |
| 전진 속도 | 0.1–0.25 mm/s |
| 수영 주파수 | 1.5–2 Hz |

## 6. 구현 계획
- `worm/body/rod2d.py`: numpy/JAX, 상태 (φ_k, r_0), 입력 (A_D, A_V) 24×2, 출력 (중심선 좌표, 곡률, 속도).
- `worm/body/muscle_map.py`: c302 근육 이름 → (행, 등/배) 매핑, 칼슘 → 활성 변환.
- 단위 테스트: (a) 사인파 활성(주파수 0.4 Hz, 파장 1 체장)을 직접 넣었을 때 전진 속도가 0.1–0.25 mm/s 범위, (b) 좌우 대칭 활성에서 직진, (c) 항력비 1.5 로 바꾸면 같은 활성에서 속도 감소.
- 신경 모델과 결합: `WormSim.run(50 ms)` 블록마다 근육 [Ca] 를 읽어 신체를 50 ms 진행 (신체 dt 0.5 ms × 100 스텝), 곡률을 다음 블록의 고유수용 입력으로.

- 채택: k_b 5, k_s 5×10⁴, dt 10 µs (명시적 적분 안정 조건 dt·k_s/C_t < 2 를 만족). 굽힘 강성이 항력에 비해 충분히 커야 몸이 선호 곡률을 따라가고 진행파가 되며, 그때 전진 속도가 문헌 범위(0.1–0.25 mm/s)에 들어온다.
- 수영 항력비(C_n/C_t = 1.5)에서는 같은 파형으로 속도가 감소(테스트로 고정). 길이 보존 오차 < 0.1%.
- 비용: 시뮬 6 s 에 2 s (실시간의 3배). 신경 모델(dt 0.25 ms)과 50 ms 블록으로 결합 시 신체는 블록당 5,000 스텝.
- 미결: 힘 단위는 C_t = 1 로 정규화한 무차원 값이라 실제 큐티클 강성과의 대응은 정하지 않았다. 문헌값과 비교할 수 있는 것은 운동학(속도, 파장, 주파수)뿐이며, 이것이 검증 지표다.
