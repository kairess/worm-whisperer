# Worm Gym — 고정된 커넥톰을 강화학습으로 가르친다 (두 번째 프로젝트 계획)

작성 2026-09-03. 첫 프로젝트(언어 → 화이트리스트 자극 → 커넥톰 → 행동)의 결론은 "번역기는 누구나 만들 수 있고, 남는 자산은 커넥톰이 고정된 빠른 전체 벌레 시뮬레이터와 그것이 못 하는 일의 목록" 이었다. 두 번째 프로젝트는 그 자산으로 **"이 뇌로 무엇까지 할 수 있는가"** 를 묻는다. 번역기 자리에 학습 에이전트를 놓고, 행동 공간은 첫 프로젝트와 똑같이 화이트리스트 뉴런 자극으로 제한한다.

## 0. 원칙 (첫 프로젝트에서 이어받음)
- 커넥톰 불변. 에이전트는 운동뉴런·근육을 건드릴 수 없다 (`worm/llm/protocols.py` 의 채널만).
- 커넥톰 밖 가정(Boyle 운동층, SMD 조향, RIV 오메가, RIS 정지)은 ADR-012/013/016 그대로. 새 가정은 ADR 로.
- **판정 기준은 학습 전에 고정한다** (아래 각 가설의 "판정"). 학습 후에 기준을 고르면 발견이 아니다.
- 부정 결과도 기록한다.

## 1. 환경 (Worm Gym)
- 무대: 2D 한천. 가우시안 냄새 소스(σ 2 mm, peak 1). 시작: 소스에서 2.5 mm, 방향 무작위.
- 관측: 벌레가 실제로 아는 것만 — 코 끝 농도의 로그 수준 1개와 로그 농도의 최근 변화 4개(0.5, 1.0, 1.5, 2.0 s 전 대비, ×10). Weber 법칙형 상대 감각(ASE 는 농도 변화율에 반응). 나침반·좌표·소스 위치 없음.
  - 처음 설계(농도 원값 5개)는 실패했다: 변화량이 0.01 수준이라 정책이 관측을 무시하고 "항상 RIV+SMDV" 상수 회전(반지름 2 mm 원호)으로 퇴화, 도달률 0.22 는 원이 소스를 지나는 확률이었다 (`runs/wormgym/es_cmd_rawobs/analysis.png`, 2026-09-03).
- 행동: 0.5 s 마다 허용된 채널 각각의 자극 진폭 ∈ [0, 6] pA. 채널 집합은 실험마다 다르다 (아래).
- 보상: 매 스텝 농도 증가분 (×100) − 생존 비용 0.05 + 도달(0.5 mm 이내) 보너스 10, 도달 시 종료, 미도달 종료 시 −2 × 최종 거리. 에피소드 40 s.
  - 생존 비용·거리 벌점은 첫 CPU 실행(2026-09-03)에서 추가했다. 농도 증가분만 주면 무작위 방향 이동의 기대 보상이 음(전진만: −38)이라 "정지"(보상 0)가 국소 최적이 되어 두 실행 모두 움직이지 않는 정책으로 수렴했다.
- 대조군: (하한) 무작위 정책, 전진만(AVB 상수). (상한) 운동층을 직접 조종하는 정책 — 행동 = (전진 게이트, 후진 게이트, 머리 편향, 오메가 트리거). 커넥톰을 우회하므로 원칙 위반이지만 "회로가 얼마나 손실을 내는가" 를 재는 자 역할.
- 구현: `worm/env/gym.py` (`WormChemEnv`, numpy 경로, 분석·검증용), `worm/env/batch.py` (`BatchWormEnv`, 신경층·판독·운동층·막대·정책을 한 jit 롤아웃으로 묶은 GPU 배치 환경; numpy 경로와 동등, `tests/test_batch_env.py`). 학습 `experiments/wormgym_es.py` (OpenAI-ES, 개체군 64 × 에피소드 4 를 rollout 한 번에). GPU 처리량: B=256 에 40 s (초당 6.4 에피소드; CPU 16 코어 약 1.5). 막대 적분(10 µs) 의 순차 지연이 하한이라 B 를 키워야 이득이 난다. `experiments/wormgym_h1.py` 는 CPU 멀티프로세스 판(워커당 스레드 1개 필수 — XLA 가 프로세스마다 코어 수만큼 스레드를 띄워 부하 100 을 만들었다).

## 2. 가설과 사전 등록된 판정

### H1. 충분성 — 회로는 충분하고, Phase 3 의 화학주성 실패는 감각 변환 모델 탓이었다
- 채널: 명령·조향 (AVB, AVA, SMDD, SMDV, RIV).
- 예측: 도달률 ≥ 0.8 (무작위 시작 100 에피소드), 무작위 정책 ≤ 0.2.
- 반증: 명령·조향 채널로도 도달률 < 0.5 이면 병목은 운동·조향층. 프로젝트를 멈추고 원인(회전 속도, 감지 지연)을 본다.
- 판정 지표: 도달률, 도달 시간 중앙값, 최종 거리. 상한(운동층 직접 조종) 대비 비율은 H3 로.

### H1a. 감각 채널만으로는 안 된다 (Phase 1 부정 결과의 행동 수준 재현)
- 채널: 감각만 (ASE, AWC, AWA, ASK, ASH, PLM, ALM, AVM).
- 예측: 도달률이 무작위와 유의하게 다르지 않다 (Vfit 에서 감각→명령 선택이 끊겨 있음, RESULTS_PHASE1 7절).
- 뒤집히면 더 좋다: 정적 자극으로는 안 보이던 경로가 동적 자극 패턴으로 열린다는 뜻. 그 패턴을 분석한다.

### H2. 부호 재발견 — 정책이 실제 벌레의 항법 전략을 스스로 찾아낸다 (핵심)
실제 전략: 피루엣(Pierce-Shimomura 1999: dC/dt < 0 이면 후진+오메가턴 확률 ↑), 풍향계(Iino & Yoshida 2009: 머리 흔들며 농도 높은 쪽으로 조향).
- H2-1 (채널 AVB, AVA, RIV): 학습된 정책의 P(AVA 또는 RIV 자극 > 3 pA | dC/dt) 가 dC/dt 의 **단조 감소** 함수. 판정: dC/dt 5분위별 자극 확률의 Spearman ρ < −0.8 (에피소드 100개 집계).
- H2-2 (채널 + SMDD, SMDV): SMDD−SMDV 자극 차이의 부호가 "머리 흔들기 중 농도가 높았던 쪽" 과 일치하는 비율 > 0.7. 두 전략의 사용 비율(피루엣 빈도/분, 조향 이득)을 문헌값과 표로 비교.
- H2-3 (감각 채널까지): ASER 자극이 dC/dt 감소와 양의 상관(OFF 세포), ASEL 은 증가와 양의 상관(ON 세포)이면 "회로 구조가 그 감각 부호를 요구한다". H1a 가 성립하면 이 항목은 자동으로 무효.
- 반증: 판정 기준을 만족하지 않는 다른 전략(예: 일정 주기 회전)으로도 H1 수준의 도달률이 나오면, 실제 전략은 회로가 강제한 것이 아니다. 그 전략을 기술한다.

### H3. 제약의 비용 — 명령 개재뉴런 층은 거의 손실 없는 행동 추상화다
- 예측: 화이트리스트 정책의 도달률·도달 시간이 운동층 직접 조종 상한의 ≥ 70 %.
- 반증: < 50 % 이면 회로가 병목. H4 의 채널 절제로 무엇이 막는지 추적.

### H4. 과제 → 회로 지도
- 예측: 평지 먹이 찾기는 AVB/AVA/SMD 로 충분(RIV 절제해도 도달률 하락 < 0.1), 장애물 무대에서는 RIV 절제 시 하락 ≥ 0.3, RIS 는 정지에 보상이 있을 때만 사용(자극률 > 0.1).
- 산출: 과제 × 채널 필요성 표.

## 3. 일정
1. 1주차: 환경, ES 학습, H1 / H1a / 하한·상한 대조군. **H1 이 실패하면 여기서 멈춘다.**
2. 2–3주차: JAX 배치 시뮬레이터(vmap, GPU), PPO. H2-1, H2-2 판정. H3.
3. 4주차: H2-3, H4(장애물 무대, 정지 보상), 문서화. 언어 연결(학습된 정책의 행동을 프로토콜 어휘로 기술, 번역기를 RL 궤적으로 재학습)은 선택.

## 4. 리스크
- 시뮬레이터 속도: 블록 50 ms 당 17 ms (CPU). 40 s 에피소드 ≈ 14 s. ES 는 16 코어로 버티지만 PPO 는 배치 GPU 시뮬레이터가 필요. 1단계로 운동층+막대를 JAX 한 블록으로 묶었다 (`worm/body/motor_block.py`, numpy 경로와 1.6e-6 mm 안에서 동일, `Worm.fast_motor`). 2단계는 신경층까지 포함해 vmap 배치.
- 관측 설계가 결과를 좌우한다. 농도 이력만 주는 것은 "실제 벌레가 아는 것" 과 같게 하려는 선택이며, 대안(dC/dt 직접 제공)은 부록으로만.
- 조향 규약: 배쪽(SMDV) = 왼쪽(+각도). 오메가턴은 항상 배쪽.
- H2 는 정책 표현력에 민감하다. 작은 MLP(은닉 16)로 시작하고, GRU 는 H2-2 에서만.

## 5. 진행 기록

### 2026-09-03 저녁: H1 1차 결과 (진행 중)
- 하한 (256 에피소드, 2.5 mm, 새 보상): 정지 −9.0 / 도달 0.00, 무작위 −32.8 / 0.04, 전진만 −56.6 / 0.06. 1.5 mm: 정지 0.00, 무작위(명령·조향 채널) 0.148, 무작위(감각 채널) 0.125 (`runs/wormgym/baselines_gpu*`).
- 관측 원값 설계는 퇴화 (1절 참고). 로그 변화율 관측으로 재학습.
- 커리큘럼 1단계 (1.5 mm, 개체군 32 × 에피소드 8, 40세대, `runs/wormgym/es_cmd_near`): **도달률 0.85** (n=256, 40 s), 중앙 도달 시간 22 s. 같은 정책을 2.5 mm 에 옮기면 40 s 에 0.43 (도달자 중앙 29 s), **60 s 에 0.80** (중앙 37 s). 즉 2.5 mm 에서의 병목은 전략이 아니라 시간이다 (기어가기 0.1–0.15 mm/s 로 2.5 mm 는 직진해도 17 s 이상). 사전 등록 기준(40 s)은 유지하고 60 s 결과는 2차 지표로만 보고한다.
- 학습된 정책 함수 (`wormgym_analyze.py` 의 정책 스윕): 농도 하강(10·Δlog C < −0.1) → AVA 0.9 / AVB 0.2 / RIV 0 = **후진**; 상승 → AVB 0.65 / AVA 0.2 / RIV 1.0 = **전진 + 오메가 굽힘(작게 맴돎)**; 조향(SMDD−SMDV)은 거의 안 씀 (|차| < 0.2). 농도 수준에는 거의 무관.
  - H2-1 과 비교: "나빠지면 후진" 은 피루엣의 첫 단계(Pierce-Shimomura 1999)와 같은 방향. 오메가는 실제와 달리 후진 뒤가 아니라 **좋아질 때 머무는 용도**로 쓴다 (run-and-tumble 이 아니라 run-and-dwell). 정식 H2-1 판정은 H2 채널 조건(AVB, AVA, RIV 만)으로 별도 학습해서 한다.
  - 실현된 게이트 통계(`analysis.json`)는 회전이 농도 진동을 만드는 순환 효과 때문에 정책 스윕과 다르게 읽힌다. 전략 판정은 정책 스윕을 1차 근거로, 실현 통계를 2차로 쓴다.
- 2.5 mm 직접 학습(`es_cmd`, 개체군 64 × 에피소드 4)은 45세대(약 1시간)에서 도달률 **0.08** (n=256, 보상 +4: 농도를 잃지 않는 법만 배움). 커리큘럼 없이는 학습 신호가 부족하다고 보고 중단. 2단계(근거리 정책에서 시작, `es_cmd_curr`)로 대체.

### 2026-09-03 밤: **H1 판정 — 충족**
- 근거리 커리큘럼 80세대 최종 정책 (`runs/wormgym/es_cmd_near/theta_final.npy`)을 사전 등록 조건(2.5 mm, 40 s, 무작위 시작 256 에피소드)으로 평가: **도달률 0.812** (기준 ≥ 0.8), 중앙 도달 시간 27 s, 최종 거리 0.72 mm. 1.5 mm 에서는 0.957 (중앙 19 s). 무작위 정책 0.04 (기준 ≤ 0.2).
- 결론: 명령·조향 채널(AVB, AVA, SMDD, SMDV, RIV)만으로 커넥톰 + Boyle 운동층은 화학주성에 충분하다. Phase 3 의 화학주성 실패(RESULTS_PHASE3_4 5절)는 회로가 아니라 "농도 → ASE 전류" 감각 변환 모델(수 pA 이하, 정적 이득) 탓이었다.
- 유의: 학습에 필요했던 것 세 가지 — 정지가 최적이 되지 않는 보상(생존 비용 + 거리 벌점), 상대 변화(로그) 관측, 근거리 커리큘럼. 2.5 mm 직접 학습은 45세대에 0.08.
- 최종 정책의 전략 (`es_cmd_near/analysis.json`, 2.5 mm 96 에피소드): 정책 스윕은 40세대와 같다 — 하강 → AVA 0.93 (후진), 상승 → AVB 0.80 + RIV 1.0 + **SMDD 0.99** (전진 + 오메가 굽힘 + 등쪽 조향). 조향 사용률 0.89 (40세대에는 0.30). 궤적은 긴 직진과 급격한 방향 전환의 run-and-tumble 형 (`analysis.png`). 실현 게이트 통계(후진 0.11 → 0.16, 오메가 0.45 → 0.87, 하강→상승)는 후진 뒤 농도가 오르는 지연 효과 때문에 정책 스윕과 다르게 읽힌다.
- 커리큘럼 2단계 30세대 (`es_cmd_curr/theta_gen30.npy`): 2.5 mm 40 s 도달률 0.816 (n=256, 중앙 26 s) — 1단계 최종(0.812)과 같은 수준. 60세대 (`theta_gen60.npy`): 0.887 (중앙 25 s). **100세대 최종 (`theta_final.npy`): 0.914** (중앙 24 s, 최종 거리 0.64 mm). H1 의 최종 수치로 이것을 쓴다.
- 2단계 최종 정책의 전략 (`es_cmd_curr/analysis.json`, 2.5 mm 96 에피소드, 도달 0.95): 정책 스윕이 더 선명해졌다 — 하강 → **AVA 0.98 + SMDV 0.83** (후진하며 배쪽 머리 편향), 상승 → **AVB 0.89 + RIV 1.0 + SMDD 0.99** (전진 + 오메가 굽힘 + 등쪽 조향). 조향 사용률 0.95, (AVA−AVB) 대 dlogC/dt 분위 ρ = −0.90. 궤적은 긴 직진이 소스로 수렴하는 형태 (`analysis.png`). 오메가 굽힘은 여전히 "상승 중" 에 켜지므로 문헌의 피루엣(후진 뒤 오메가)과는 순서가 다르다 — 이 모델의 오메가 펄스는 RIV 가 켜져 있는 동안 계속 재발동되어 "작은 원 그리기" 로 쓰이기 때문. H2 판정 실험(채널 제한)에서 다시 본다.
- **H2-2 풍향계 — 불성립**: 최종 H1 정책에서 조향 부호(SMDV−SMDD)와 소스 쪽 부호의 일치율 **0.27** (n=4103 스텝, 우연 0.5, 판정 > 0.7). 조향은 좌우 기울기가 아니라 dC/dt 에 묶여 있다 (상승 → SMDD, 하강 → SMDV). 0.5 미만인 이유는 SMDD(등쪽) 편향이 RIV 오메가(배쪽 굽힘)를 상쇄해 **회전 각도를 조절하는 손잡이**로 쓰이기 때문으로 보인다. 설계 한계도 있다: 관측이 코 끝 농도 이력뿐이고 행동 간격이 0.5 s 라 머리 흔들기(약 1 Hz)에 위상을 맞출 수 없어 풍향계 전략은 원리적으로 학습 불가. 풍향계를 제대로 시험하려면 관측·행동 간격을 0.1 s 로 줄여야 한다 (후속).
- 다음: H3 상한(운동층 직접 조종, `es_direct_near`) 진행 중. H2-1(채널 AVB, AVA, RIV 만, `es_h21_*`) 2단계 커리큘럼 학습 중.

### H1a 중간 (감각 채널만, 1.5 mm, 20세대, `runs/wormgym/es_sens_near`)
- 도달률 0.07 (96 에피소드, CPU 분석). 궤적은 대부분 제자리 떨림: 감각 자극으로는 명령 뉴런이 게이트 문턱(3 mV) 근처를 오가며 파동이 서지 않는다.
- 정책 스윕: 하강 → PLM 0.90 (AVM 0.02), 상승 → AVM 0.95 + ALM 0.70 + ASK 0.83 (PLM 0.16). Vfit 에서 PLM 자극은 AVA 를 AVB 보다 약간 더 올리고(후진 게이트), ALM+AVM 은 반대이므로(RESULTS_PHASE1 3절 표), 진화는 터치 회로의 **1 mV 미만 비대칭**을 이용해 명령 채널 정책과 같은 논리("나빠지면 후진, 좋아지면 전진")를 구현하려 했다. 생물학적 방향(PLM → 전진)과는 반대인데, 이는 Vfit 의 터치 회로 방향이 반대라는 Phase 1 결과와 일치한다.
- 20세대 정책의 256 에피소드 평가: 도달률 0.105 vs 1.5 mm 기준선 무작위(감각 채널, 큰 무작위 가중치) 0.125, 정지 0.000.
- **H1a 판정 — 성립 (예측대로 실패)**: 80세대 최종 정책 (`es_sens_near/theta_final.npy`) 도달률 **0.109** (n=256) vs 무작위 0.125. 학습 곡선도 80세대 내내 평균 보상 −7 ~ −14 로 정지(−7) 근처. 감각 채널만으로는 Vfit 커넥톰이 명령을 선택하지 못한다 — Phase 1 의 정적 자극 결과(RESULTS_PHASE1 7절)가 동적 자극·학습 정책에서도 유지된다. 따라서 H2-3(감각 부호 재발견)은 무효.
- 같은 과제에서 명령·조향 채널 정책은 0.957 (1단계 최종). 두 조건의 차이가 "감각→명령 선택" 한 단계의 몫이다.

### H3 (제약의 비용) — 상한 대조군 재설계
- 학습된 direct 정책(`es_direct_near`, 운동층 직접 조종, 1.5 mm, 80세대)은 **정지에 갇혔다** (보상 −7 = 정지, 도달 0.00). 원인: direct 행동이 0.5 문턱의 이진 게이트라 시그모이드가 포화되면 ES 섭동이 행동을 못 바꾼다. 화이트리스트 경로는 자극 진폭이 신경 판독을 거쳐 연속적으로 게이트 근처를 오가므로 오히려 학습이 잘 된다 — 이것 자체가 "명령 개재뉴런 층이 좋은 행동 인터페이스" 라는 H3 의 한 측면이다.
- 학습된 상한이 화이트리스트보다 못하면 상한이 아니므로, 상한을 **소스 방향을 아는 오라클 조종기**(`experiments/wormgym_oracle.py`: 항상 전진, 머리 편향 = 소스 쪽)로 바꾼다. 같은 몸·운동층으로 갈 수 있는 물리적 최속. H3 판정은 화이트리스트 정책의 도달률·중앙 도달 시간을 오라클과 비교 (기준 ≥ 70 % 유지).
- 화이트리스트 최종 정책(`es_cmd_curr/theta_final.npy`): 1.5 mm 도달 0.996 (중앙 17.5 s), 2.5 mm 0.914 (중앙 24 s).
- 오라클 직접 조종 (`runs/wormgym/oracle/`, n=256, 40 s): 비례 조향 이득 1/2/3, 오메가 옵션, 후진 옵션 조합 중 최고 — 1.5 mm **0.676** (후진 옵션, 중앙 8.0 s), 2.5 mm **0.895** (이득 2, 후진 없음, 중앙 16.5 s). 후진 없는 조향만으로는 1.5 mm 에서 0.434 (반경 1 mm 궤도).
- **H3 판정**: 도달률은 화이트리스트 정책이 오라클보다 높다 (1.5 mm 0.996 vs 0.676, 2.5 mm 0.914 vs 0.895 → 비율 > 100 %). 도달 시간은 느리다 (중앙 17.5 vs 8.0 s = 46 %, 24 vs 16.5 s = 69 %). 사전 등록 기준(≥ 70 %)은 도달률로는 충족, 시간으로는 2.5 mm 에서 경계, 1.5 mm 에서 미달. 단 오라클은 소스 방향을 알고 직진하므로 시간 차이에는 "커넥톰 제약의 비용" 과 "방향을 모르는 비용" 이 섞여 있다. 학습된 direct 정책(같은 정보 조건)은 정지에 갇혀 비교 불가. 결론: 명령 개재뉴런 층은 도달률 면에서 손실 없는 행동 인터페이스이고, 속도 비용의 분리는 후속(direct 모드의 연속 행동 재설계) 과제.


### H2-1 (채널 AVB, AVA, RIV 만) — 1단계 결과: 규칙은 피루엣, 능력은 부족
- 1.5 mm 80세대 (`runs/wormgym/es_h21_near`): 도달률 **0.113** (n=256; 무작위 0.148 과 차이 없음). 2단계(2.5 mm)도 45세대까지 도달 0.
- 그런데 정책 스윕은 문헌의 피루엣 규칙 그대로다: 하강 → **AVA 0.99 + RIV 0.93** (후진 + 오메가), 상승 → **AVB 0.99** (전진 달리기), 변화 없음 → 거의 무자극. (AVA−AVB) 대 dlogC/dt 분위 ρ = **−1.00**. 실현된 후진/오메가 확률도 하강 분위에서 0.46 으로 최고 (2–4 분위 0.05–0.17; 5 분위 0.25 는 후진 뒤 농도 상승의 지연 효과) — 전체 ρ 는 −0.30 이라 사전 등록 기준(−0.8)은 실현 지표로는 미달, 정책 스윕으로는 충족.
- 해석: 후진·오메가만으로는 방향 전환이 약 180° 한 종류뿐이라 되돌아가기만 하고 새 방향을 못 잡는다. 궤적은 짧은 왕복과 제자리 떨림 (`analysis.png`). 실제 벌레의 피루엣은 오메가 각도가 분포를 가지며(Gray 2005) 머리 조향과 결합된다. 이 모델에서는 SMD 조향(H1 채널 집합)이 있어야 오메가가 "각도 조절 가능한 회전" 이 되어 항법이 성립한다 — H2-2 의 "SMDD 가 오메가를 상쇄해 회전각을 조절" 관찰과 일치.
- 2단계(2.5 mm, 100세대, `es_h21_curr`) 최종: 도달률 0.051 (n=256) — 항법 불가 확정.
- 판정: H2-1 은 "정책이 피루엣 규칙을 찾는다" 는 부분은 성립, "그 정책이 항법에 충분하다" 는 부분은 불성립. 즉 이 커넥톰+운동층에서 순수 run-and-tumble 은 부족하고 조향이 필요하다.

### 2026-09-04: H4 (과제 → 회로 지도)
- H4-1 평지 절제: 최종 H1 정책(`es_cmd_curr/theta_final.npy`)에서 채널을 하나씩 막고(행동 마스크, `--ablate`) 2.5 mm 40 s 도달률을 잰다. 사전 예측: RIV 절제 시 하락 < 0.1.
- H4-2 머무르기 과제(`--dwell`): 도달해도 종료하지 않고 반경 안 스텝마다 +0.5. 채널에 RIS 를 추가(AVB, AVA, SMDD, SMDV, RIV, RIS)하고 H1 정책을 확장해(`--init_channels`, 새 채널 출력 0/편향 −3) 이어서 학습. 사전 예측: RIS 자극률 > 0.1 로 정지를 쓴다. 대안 전략(오메가로 제자리 맴돌기)이 나오면 그것도 기록.
- 장애물 무대는 막대 모델에 충돌 물리가 없어 이번에는 하지 않는다.
- **H4-1 결과 (`runs/wormgym/h4/`, 2.5 mm 40 s, n=256, 최종 H1 정책의 행동 마스크 절제)**:

| 절제 채널 | 도달률 | 비고 |
|---|---|---|
| 없음 | 0.914 | |
| AVB | 0.434 | 전진 게이트는 RIV/SMD 자극의 갭정션 확산으로도 일부 열린다 |
| AVA | 0.098 | 후진 불가 → 항법 붕괴 |
| SMDD | 0.410 | |
| SMDV | 0.621 | |
| SMDD+SMDV | 0.273 | 조향 없이는 절반 이하 |

  - 해석: 이 정책의 항법은 "하강 → 후진(AVA), 상승 → 전진 + 오메가(RIV) + 조향(SMD)" 이라 세 요소 모두 필요하다. H2-1(SMD 없이 재학습 → 0.05)과 합치면 이 커넥톰+운동층에서는 후진·오메가·조향이 **모두** 있어야 화학주성이 성립한다. 사전 예측은 "평지는 조향으로 충분" 이었으나 틀렸다. 절제는 "학습된 정책에서의 필요성" 이므로 RIV 없이 재학습하는 충분성 판(`es_noriv_*`)을 추가로 돌린다.
- **H4-2 결과 (`runs/wormgym/es_dwell`, 100세대, 2.5 mm, n=256)**: 도달 0.930, 반경 안 체류 비율 0.329, 보상 +68. **RIS 사용 0** (평균 행동 0.03, 반경 안 0.02, 0.5 초과 비율 0.0). 반경 안에서는 RIV 0.72 + AVB 0.25 — 오메가 굽힘으로 작은 원을 그리며 머문다. 예측("RIS 자극률 > 0.1") **반증**. 해석: 이 보상에서는 정지와 맴돌기의 보상이 같고(둘 다 반경 안 +0.5, ΔC ≈ 0), 맴돌기는 이미 가진 전략이라 새 채널(RIS, 초기 편향 −3)을 켤 압력이 없다. 이동 비용(스텝당 머리 이동 mm × 5)을 넣은 변형 `es_dwell_cost` 로 "정지가 유리할 때 RIS 를 쓰는가" 를 본다.
- **H4-1 충분성 판 (RIV 없이 재학습, `es_noriv_near` → `es_noriv_curr`)**: 1.5 mm 80세대 0.117 (무작위 0.148), 2.5 mm 100세대 **0.191**. 오메가 없이는 후진+조향으로도 항법이 서지 않는다. H2-1(조향 없이 0.05), H4-1 절제(RIV 0.066, AVA 0.098)와 합쳐 결론: **이 커넥톰+운동층에서 화학주성의 최소 회로는 후진(AVA) + 오메가(RIV) + 조향(SMD) 셋 모두**다.
  - 주의(관측 설계 의존): 오라클은 방향을 알면 비례 조향만으로 2.5 mm 0.895 를 낸다. 즉 몸은 조향만으로도 갈 수 있다. 정책이 조향만으로 못 가는 이유는 관측이 코 끝 농도의 시간 이력뿐이라 좌우 정보가 없기 때문이며(H2-2 논의), 시간 정보만으로 하는 klinokinesis 는 큰 재정향(오메가)이 있어야 성립한다. 이는 실제 벌레가 시간 감각으로 피루엣을, 머리 흔들기 표본으로 풍향계를 쓰는 구도와 같다. 0.1 s 관측 후속에서 다시 본다.
- **H4-2 이동 비용 변형 (`es_dwell_cost`, 스텝당 이동 mm × 5, 100세대)**: 도달 0.879, 체류 0.333, **RIS 여전히 0** (반경 안 0.02). 대신 반경 안에서 모든 명령 드라이브를 낮춘다 (AVB 0.26, AVA 0.15, RIV 0.30, SMD 0.2) — 게이트 문턱(3 mV) 아래로 내려 운동층을 끄는 "드라이브 철회" 로 정지한다. 예측 재반증. 해석: 에이전트가 AVB/AVA 를 직접 쥐고 있으면 RIS 는 불필요하다. RIS 는 전진 드라이브가 외부에서 유지될 때(첫 프로젝트의 "AVB 켠 채 RIS" 프로토콜)만 의미가 있다. 실제 벌레에서 RIS 가 필요한 이유(수면 중에도 명령 회로가 켜질 수 있음)를 시험하려면 AVB 를 에이전트가 끌 수 없는 과제가 필요하다 (후속).

후속 후보: 0.1 s 관측·행동으로 풍향계 시험; direct 모드 연속 행동 재설계로 H3 시간 비용 분리; AVB 를 끌 수 없는 과제로 RIS 시험; PPO 로 ES 보다 큰 정책.

## 7. H5: 미로 항법 (2026-09-04 시작, 자율 모드)

### 문헌 비교점
- Qin & Wheeler 2007 (Lab Chip): 미세유체 미로에서 야생형은 탐색 후 출구/먹이에 도달, 도파민 결핍 cat-2 는 탐색·학습 저하.
- Gourgou et al. 2021 (iScience): 한천 T-미로. 먹이 팔 도달은 화학 + 기계감각(터치) + 고유수용의 다감각 행동. 지표: 결정 지수 DI = (nL − nR)/(nL + nR), 도달 시간(30분 이내). 훈련 후 학습 지수 LI. 도파민·CREB 관여. STAR Protocols 2021 (PMC8710835) 에 규격.
- eLife 2024 프리프린트 96143 (회전 통계): 경계(SDS) 7 mm 안에서 도피 회전은 이산 선택 — 큰 배쪽 δ-턴 확률 0.18 → 0.40, 등쪽 0.24 → 0.16. 재정향 각 분포는 자유 탐색과 같다. 최적 탐색은 재정향률 = 경로 곡률일 때.
- pH 회피 (PMC4653917): 급격한 자극에는 후진-회전(무작위 재정향), 완만한 자극에는 곡선(비무작위 재정향) — 두 기동이 다른 문턱으로 선택된다.
- Park et al. 2008 (PLoS ONE): 기둥 배열(지름 300 µm, 간격 425–475 µm ≈ 파장 650 µm 에 맞을 때)에서 벌레는 양쪽 기둥을 밀며 액체보다 10배 빠른 1.3 mm/s. 기계감각 변이체 mec-4/mec-10 는 못 한다. 즉 실제 벌레는 벽·기둥 접촉을 추진에 쓴다. 우리 막대 모델은 벽 척력만 있고 마찰·밀기가 없어 통로에서 오히려 느려진다(0.07–0.10 mm/s) — 모델 한계로 기록.

### 환경 (추가)
- 벽: 막대 노드가 벽 선분에서 wall_r = 60 µm 안으로 들어오면 척력 (에너지 ½ k_w (wall_r − d)², k_w 5×10³; `Rod2D(walls=…)`). 통로는 중심선 폴리라인 + 폭으로 생성 (`corridor_walls`).
- 관측 (추가): 머리 4 노드의 벽 접촉 강도 (좌, 우, 정면) ∈ [0,1] (`wall_touch`). 실제 벌레는 터치 뉴런으로 느끼지만 이 모델은 감각→명령 경로가 끊겨 있으므로(H1a), 접촉 정보는 에이전트에게 직접 준다. 원칙: 여전히 명령·조향 채널만 자극.
- 무대: (a) 꺾인 통로(90°), (b) T-미로(줄기 3 mm, 팔 2 mm, 폭 0.4 mm; 한 팔 끝에 냄새 소스), (c) 3×3 격자 미로. 크기는 체장 1 mm 기준.

### 가설과 사전 등록 판정
- **H5-1 (벽 물리 유효성)**: 벽을 향해 기어가면 미끄러져 따라가고 침투 < wall_r, 폭 0.4 mm 통로 안에서 오메가턴은 벽에 막혀 재정향 < 90°. (검증 실험, 가설이라기보다 전제)
- **H5-2 (통로에서는 후진, 개활지에서는 오메가)**: 꺾인 통로·T-미로에서 학습된 정책은 막다른 끝에서 오메가 대신 **후진(AVA)** 을 쓴다. 판정: 벽 정면 접촉 > 0.5 인 스텝에서 AVA 자극 > 3 pA 비율 ≥ 0.6, RIV < 3 pA 비율 ≥ 0.6; 같은 정책을 개활지(2.5 mm 평지)에서 평가하면 오메가 사용 유지. 근거: 실제 벌레도 좁은 통로에서는 후진하고, 급격 자극에 후진-회전을 고른다 (PMC4653917).
- **H5-3 (다감각 필요성, Gourgou 2021 재현)**: T-미로 먹이 팔 도달률은 [냄새 + 접촉] 정책 > [냄새만] 정책 > [접촉만] 정책. 판정: 각 조건 256 에피소드, 차이 ≥ 0.15. 접촉만으로는 팔 선택이 우연(DI ≈ 0), 냄새만으로는 벽에 걸려 도달률 하락.
- **H5-4 (벽 따라가기의 창발)**: 접촉 관측을 준 정책은 한쪽 벽을 따라가는 편향(좌/우 접촉 시간 비율의 비대칭 > 0.6:0.4)을 보인다. 이것은 단순 연결 미로를 기억 없이 푸는 반응 전략이다. 판정: 3×3 미로 도달률 ≥ 0.5 이면서 좌/우 접촉 비대칭.
- **H5-5 (경계 도피 통계 재현, eLife 2024)**: 학습된 정책의 재정향 각 분포는 벽 근처와 개활지에서 같고(KS p > 0.05), 벽 근처에서 큰 회전(> 135°)의 비율이 개활지의 약 2배 (0.18 → 0.40 에 상응).
- 반증 조건: H5-2 가 뒤집혀 통로에서도 오메가를 쓰면 이 모델의 벽 척력이 너무 약하거나(침투) 운동층이 벽 반력을 못 느끼는 것이므로 물리부터 다시 본다.

### H5-1 결과 (2026-09-04): 벽 물리 유효

- 오메가턴은 통로 폭 0.4 mm 에서는 완전히 되지만(굽힘 지름 0.34 mm) **0.3 mm 이하에서는 막힌다** (재정향 +2°). 무대 폭은 0.3 mm 로 정한다 (몸 폭의 약 4배; 미세유체 채널과 같은 비율).
- 좁은 통로에서 전진 속도는 0.07–0.10 mm/s 로 개활지(0.15–0.18)의 절반 (벽 접촉이 파동을 방해). 실제 벌레도 채널에서 보행이 바뀐다.

### 문헌 대조 (2026-09-04): 실제 벌레는 T-미로에서 선천적 좌/우 편향이 없다
- Gourgou 2021 의 대조군: 빈 T-미로에서 결정 지수 DI ≈ 0 — "선천적 handedness 없음". 학습 후에는 먹이 팔 쪽으로 편향(정답 편향 87–89 %). 모델링 논문(EJN 2022, "Modelling learning in C. elegans chemosensory and locomotive behaviour")은 학습된 벌레가 교차점에서 이산 선택을 하는 것이 아니라 **시험 내내 정답 쪽으로 작고 일정한 회전 편향(등쪽/배쪽)** 을 가진다고 본다.
- 우리 모델의 불일치: 평지 정책은 T 교차점에서 항상 배쪽(왼쪽)으로 꺾는다 (DI = −1 에 해당). 원인은 정책이 "농도 상승 중에는 RIV 오메가 드라이브를 켜 두는" 습관이고, 통로가 오메가를 막으면 그 배쪽 굽힘이 벽에 눌려 좌회전이 된다. 실제 벌레는 통로에서 이 드라이브를 억제하거나 조향으로 상쇄해야 DI ≈ 0 이 된다. → **모델 예측: 통로 안 오메가 드라이브의 지속은 벌레에게 없는 인공물이며, 벌레는 좁은 통로에서 RIV 활성을 억제한다.** (실험적으로 검증 가능: 미세유체 통로 안 RIV 칼슘 이미징.)
- 사전 등록 추가 **H5-3'**: 냄새+접촉으로 학습한 T-미로 정책은 팔을 교차점의 이산 선택이 아니라 **줄기 구간부터의 조향 편향(SMDD−SMDV) 부호** 로 고른다. 판정: 줄기 구간 편향 부호와 목표 팔의 일치율 > 0.7 (`wormgym_maze_analyze.py` 의 H5-3'). 이것이 성립하면 EJN 2022 의 기전과 같다.

### 결과 2: RIV 절제 (평지 정책, T-미로, 128 에피소드)

### 결과 3: 상수 조향 시험 (T-미로, 32 에피소드씩, `runs/wormgym/h5/steer_test.out`)
- AVB + SMDD(등쪽 = 오른쪽), AVB + SMDV(배쪽 = 왼쪽), AVB + SMDD 강 — 세 조건 모두 **팔 도달 0/32**. 머리는 교차점 벽에서 멈추고 옆으로 0.2 mm 만 밀린다. 즉 머리 조향(앞쪽 12행 편향)은 폭 0.3 mm 통로의 90° 모퉁이를 돌기에 너무 약하다.
- 종합하면 이 모델에서 좁은 통로의 모퉁이 회전은 **깊은 굽힘(오메가 드라이브)이 벽에 눌리는 것** 으로만 가능하고, 굽힘이 배쪽뿐이므로(ADR-016) **왼쪽 모퉁이만 돌 수 있다**. 오른쪽 팔에 가는 유일한 경로는 왼쪽 팔 끝(막다른 곳)에서 후진해 팔 통로를 거꾸로 거슬러 가는 것이다 (2 mm × 2 = 4 mm, 후진 0.1 mm/s 로 약 40 s).
- **예측 (검증 가능)**: (1) 실제 벌레가 좁은 T-미로에서 선천적 편향 없이(DI ≈ 0, Gourgou 2021) 양쪽 팔에 가려면 교차점에서 등쪽 깊은 굽힘(dorsal Ω, 자유 탐색에서 24 %; eLife 2024)을 배쪽과 비슷한 빈도로 써야 한다. (2) 등쪽 회전이 줄어든 조건(경계 도피 상태에서는 0.16)이나 등쪽 회전 결손 변이체는 좁은 T-미로에서 배쪽 팔 편향(DI ≠ 0)을 보일 것이다. (3) 교차점 통과 순간의 굽힘 방향(등/배)이 팔 선택을 예측한다 — 고속 촬영으로 직접 검증 가능.
- 모델 후속: 가상의 "등쪽 오메가" 드라이브를 (오라클처럼 원칙 위반을 명시한) 변형으로 추가해, 등쪽 굽힘이 있으면 DI ≈ 0 과 도달률 상승이 나오는지 본다 (H5-6). `BatchWormEnv` 의 가상 채널 `DOMEGA` (뉴런 전류 없음, 등쪽 굽힘 펄스 +9 발사).
- 주의 (오메가 펄스의 재장전): 펄스는 RIV 가 문턱(30 mV)을 **넘는 순간** 한 번 발사되고 RIV 가 내려가야 다시 장전된다. 상수 AVB+RIV 는 줄기에서 한 번 쏘고 끝나 0/32 (`domega_test.out`). 평지 정책은 농도 하강→RIV 끔 / 상승→켬을 반복해 모퉁이마다 재장전했다. 시험은 "정면 접촉 → 오메가" 반응 규칙으로 다시 (`reactive_omega_test.py`).
- 3×3 격자 학습(냄새+접촉, `grid_touch_odor`)은 10세대째 도달 0 (보상 정체 +44). 시작 노드에서 목표까지의 경로에 **오른쪽 회전이 2번** 필요하므로(서→북, 북→동) 배쪽 오메가만으로는 원리상 불가능하다. 중단하고 H5-6(등쪽 오메가 변형)에서 다시 돌린다. 이것 자체가 예측 (1) 의 모델 내 확인이다.

### 문헌 대조 2: 깊은 굽힘의 방향은 SMDD/SMDV 가 정한다
- bioRxiv 2024.08.11.607076 → Nature Neuroscience 2026 "Neural sequences underlying directed turning in C. elegans": 후진 뒤 회전에서 **SMD 는 오메가 진폭, RIV 는 배쪽 편향**을 담당하고, 등/배 방향은 **SMDD 대 SMDV**(RMD 가 선택)가 정한다. SMDV·RMDV·RIV 는 배쪽 회전에서 더 활성. 즉 등쪽 깊은 굽힘 = SMDD 활성 + (RIV 편향 없음).
- 같은 논문의 추가 사실: 후진 중 **SAAV** 활성이 다가올 회전 방향(배쪽이면 높음)을 미리 예측하고, 벌레는 **기울기 방향에 따라 등/배 회전을 선택**한다(자발 행동 대비 정답 방향 비율의 "작지만 유의한 증가"; 방향 오차 135–180° 이면 더 큰 각도의 회전). 즉 실제 벌레의 T-미로 팔 선택 능력은 "회전 방향의 감각 의존 선택" 이라는 알려진 기능에 해당한다. RIM 티라민이 이 순서를 조정.
- 모델 함의: ADR-016 은 펄스를 RIV 단독·배쪽 고정으로 두었다. 문헌대로 하면 펄스 방향 = SMDD−SMDV 부호(RIV 는 진폭·배쪽 기본값)여야 하고, 그러면 가상 채널 DOMEGA 없이 **화이트리스트 자극(RIV + SMDD)** 만으로 등쪽 깊은 굽힘이 가능하다. `omega_smd_dir` 플래그로 구현 (배치 환경·Worm 둘 다; 차 > 10 mV 이면 등쪽). ADR-017 후보 — `smd_dir_test` 결과로 채택 여부 결정 (평지 H1 과제와 첫 프로젝트 프로토콜이 깨지지 않아야 함).

- 방향 규칙을 켜면 이 정책의 펄스는 전부 등쪽이 된다(농도 상승 시 SMDD 0.99 를 켜기 때문) → 모든 에피소드가 오른쪽 팔. 굽힘 방향 = 모퉁이 방향임이 양쪽에서 확인. 다만 옛 규칙에 맞춰 학습된 정책이라 새 규칙에서는 평지 화학주성과 L-통로가 깨진다 → 새 규칙으로 **재학습**해야 공정한 시험이 된다.
- DOMEGA 스왑판(등쪽 고정)이 양쪽 팔에 다 가고 도달 1.00 인 것은 후진 단계의 배쪽 머리 편향(SMDV)과 등쪽 펄스가 합쳐져 양방향 레퍼토리가 되기 때문 (궤적 `dorsal_swap_paths.png`).
- 궤적 해석 (`dorsal_swap_paths.png`): 등쪽판은 교차점에서 일단 오른쪽으로 꺾고, 목표가 왼쪽이면 농도 하강 → **후진(배쪽 머리 편향 SMDV)** 으로 되돌아 왼쪽 팔로 간다. 배쪽판은 왼쪽으로 꺾은 뒤 오른쪽으로 교정할 수단이 없어 왼쪽 팔에서 맴돈다. 즉 "등쪽 깊은 굽힘 + 배쪽 편향 후진" 이 양방향 레퍼토리이며, 방향 선택은 교차점의 이산 결정이 아니라 **후진 단계의 편향**이 담당한다 — Nature Neurosci 2026 의 "후진 중 SAAV 활성이 회전 방향을 예측" 과 같은 구조.
- 결정: ADR-017 후보 규칙(문헌 근거 있음, 화이트리스트 안)을 채택 방향으로 두고, 그 규칙 아래에서 평지 화학주성 → T-미로 순으로 재학습한다 (`--omega_smd_dir`). 가상 채널 DOMEGA 는 기전 확인용 대조군으로만 남긴다.

### 결과 5: H5-3 A — 냄새+접촉으로 학습한 T-미로 정책 (`tmaze_touch_odor`, 40세대, 128 에피소드)
- 도달률 **1.00**, 목표 팔 선택률 **1.00**, 중앙 도달 40 s. 배쪽 굽힘만 있는 ADR-016 규칙 아래에서도 냄새로 팔을 고르는 법을 학습했다. 줄기 구간 조향 편향(H5-3')은 아니다(일치율 0.51, 편향 크기 0.11–0.16). 벽 정면 접촉 시 행동은 여전히 AVB+RIV(후진 0.01). 좌/우 접촉 0.13/0.05, 벽 근처 큰 재정향 0.41 vs 개활 0.02.
- 기전 (`junction_actions.out`, 64 에피소드): 학습 후에도 **첫 진입 팔은 64/64 왼쪽**(배쪽 굽힘의 선천 편향 유지). 목표가 오른쪽이면 교차점·팔 구간 체류가 3배(1848 vs 651 스텝)이고 후진 명령 비율이 0.05 → 0.25. 즉 전략 = "항상 왼쪽으로 꺾고, 농도가 떨어지면 **긴 후진으로 팔 통로를 거슬러 반대 팔까지**". 회전 방향을 바꾸는 대신 후진 길이로 오류를 교정한다 — Nature Neurosci 2026 의 "방향 오차 135–180° 에서 더 큰 재정향" 과 같은 논리의 모델판.
- 도달 시간 (`side_time.out`, 128 에피소드; 시작 자세 고정이라 편차 0): 목표 왼쪽 **22 s**, 목표 오른쪽 **40 s** — 잘못된 쪽의 비용 18 s. 오른쪽 목표에서 연속 후진 명령의 최장 길이는 2 s 뿐이다: 한 번의 긴 후진이 아니라 **2 s 후진 발작의 반복**으로 팔 통로를 따라 꼬리 쪽으로 순이동한다 (통로 안 klinokinesis: 전진 = 농도 하강 → 후진, 후진 = 상승 → 전진, 후진 구간이 조금 더 길어 순이동).
- 실제 벌레와의 차이: 벌레는 첫 팔 편향이 없다(DI ≈ 0). 모델은 편향 + 교정으로 같은 성공률을 낸다. 따라서 "선천 편향 없음" 은 성공률로는 구별되지 않고 **첫 진입 팔 분포와 도달 시간의 좌/우 비대칭**으로만 구별된다 — 실험 지표 제안: T-미로에서 (a) 첫 진입 팔의 편향, (b) 목표 팔별 도달 시간 차, (c) 잘못된 팔에서의 후진 길이.

### 결과 7: H5-3 C — 접촉만 (`tmaze_touch_only`, 냄새 관측 차단, 40세대, 128 에피소드)
- 도달 **0.00**, 팔 결정 0.00. 정책은 모든 채널 무자극(정지)으로 수렴 (보상 +4.6; 냄새 정보 없이 움직이면 평균적으로 손해). ES 의 "정지" 국소 최적(H3 의 direct 모드와 같은 현상)이 섞여 있어 "접촉만으로는 불가" 의 강한 판정은 유보하지만, 접촉 정보만으로 팔을 고를 근거가 없다는 점은 설계상 자명하다.
- **H5-3 판정 (Gourgou 2021 다감각 재현)**: [냄새+접촉] 1.00 > [냄새만 = 평지 정책] 0.49 > [접촉만] 0.00. 예측된 순서 성립, 차이 ≥ 0.15 충족.
- **접촉 관측 절제** (`analysis_zerotouch.txt`, 같은 정책, 접촉 입력 0, 64 에피소드): 도달 **1.00**, 목표 팔 **1.0**, 중앙 도달 **29.8 s** (접촉 있을 때 40 s 보다 빠름). 즉 학습된 정책은 접촉 관측을 **쓰지 않으며** 오히려 약간 방해된다. 이 모델의 "다감각" 은 냄새 + **벽 물리**(몸이 벽에 눌려 도는 것)이지 접촉 감각이 아니다. Gourgou 2021 의 "기계감각 필요" 는 이 모델에서는 감각이 아니라 신체–벽 상호작용으로 대체된다 — 실제 벌레에서 mec 변이체가 미로를 못 푸는 이유가 감각 정보인지 벽 추진(Park 2008)인지 구별해야 한다는 제안.
- 냄새만 학습 (`tmaze_odor_only`, 접촉 관측 없음, 40세대, 128 에피소드): 도달 **1.00**, 목표 팔 **1.0**, 중앙 40 s — 예측대로 냄새+접촉 학습과 같다. **H5-3 최종**: 이 모델의 T-미로 해결에는 냄새 + 벽 물리 + 학습(오류 교정 후진)이면 충분하고 접촉 감각은 불필요하다. 실제 벌레에서 기계감각이 필요한 이유(Gourgou 2021)는 이 모델 밖의 기전 — 벽 접촉을 추진에 쓰는 것(Park 2008) 또는 학습(기억) 형성에 쓰는 것 — 으로 좁혀진다.

- 추가 시험 (`smddir/tmaze_press`): 생존 비용 0.05 → 0.2 로 시간 압력을 키우고 60세대 더 학습해 "냄새로 굽힘 방향 선택" 이 창발하는지 (판정: 첫 진입 = 목표 팔 비율 > 0.7).
- 격자(ADR-017, `smddir/grid`)는 20세대째 도달 0 (보상 정체) — 오른쪽 회전 2번을 한꺼번에 찾아야 해 탐색이 어렵다. 최소 판정으로 **R-통로 학습** (`smddir/corridor_R`, 오른쪽 모퉁이 하나, 40세대)을 추가: 진화가 새 규칙에서 오른쪽 회전을 배우면(도달 ≥ 0.5) 등쪽 굽힘의 실효성 확인, 못 배우면 규칙이 아니라 탐색 문제.
- **R-통로 학습 결과 (ADR-017, `smddir/corridor_R`)**: 20세대에서 학습 시드 도달률 **0.94** (배쪽 고정 규칙에서는 어떤 정책도 0/32). 즉 등쪽 굽힘 규칙 아래에서 진화는 오른쪽 모퉁이를 배운다 — 채택 조건 (R-통로 ≥ 0.5) 방향으로 충족. 최종 64 에피소드 판정과 같은 정책의 L-통로 통과율(양방향 유지 여부)은 `corridor_R/analysis*.txt`.

ES 평균이 그것을 유지하지 못한 것은 개체군 대부분이 실패하는 좁은 해 영역이기 때문. 강건성(`grid_fromR/robust.txt`): 시작 자세 흔들기(위치 ±0.1 mm, 방향 ±10°)만으로 도달 **0.047** — 고정 시작에 맞춘 열린 고리 순서열이지 상황 의존 전략이 아니다. 그러나 같은 개체가 **L-통로 1.00, R-통로 1.00** 을 모두 통과하고 접촉 관측을 0 으로 하면 격자 0.00 이 된다 — 즉 접촉 관측으로 열린 쪽을 읽어 양쪽으로 도는 **양손 정책**이 실제로 존재하며(시간 이력만으로는 한손잡이였던 것과 대비), 격자 실패는 4회 회전 순서열의 민감도 문제다. **H5-4 판정**: 벽 따라가기 편향은 창발(결과 1)했고 접촉 관측 기반 양손 회전도 가능하지만, 3×3 격자의 강건한 해(도달 ≥ 0.5)는 얻지 못했다.
- 시간 압력 계속 학습 (`smddir/tmaze_press`, 생존 비용 0.2, 60세대, 128 에피소드): 첫 진입 **L 128 / R 0** 그대로, 오른쪽 목표 교정만 빨라짐 (64.5 → 32.5 s; 왼쪽 24.5 s). 굽힘은 강한 배쪽 0.80 으로 되돌아갔다.
- 체인 정책들의 좌/우 통로 (`smddir/corridor_LR.txt`, 64 에피소드): 평지·T-미로·격자 정책 모두 L-통로 1.00, **R-통로 0.00**. 즉 등쪽 굽힘 규칙 아래에서도 오른쪽 회전은 과제가 요구할 때만(R-통로 학습) 생기고, 요구되지 않은 정책은 왼쪽 회전 습관을 유지한다. 격자 정책은 L-통로도 109.5 s 로 느림(격자에서 배운 것이 없음).
- **H5-6 판정**: 등쪽 굽힘이 가능해도(R-통로는 배움) 학습은 "교차점에서 냄새로 방향 선택" 을 만들지 않았다. 이유는 정보에 있다: 관측이 코 끝 농도의 **시간 이력뿐**이면 교차점에서 두 팔의 농도는 같고, 어느 팔이 맞는지는 **들어가 봐야** 안다. 따라서 "한쪽 먼저 + 틀리면 교정" 은 이 감각 조건에서 정보 이론적으로 최선에 가깝고, 등쪽 옵션은 그 전략을 바꿀 이유가 못 된다. 실제 벌레의 편향 없는 올바른 첫 선택(Gourgou 2021 훈련군 87–89 %)은 교차점에서 **좌우 기울기를 표본하는 감각**(머리 흔들기, Nature Neurosci 2026 의 SMBV 감각 정보)이 있어야 가능하다는 예측이 된다.
- 따라서 미로 항법의 최종 후속 과제는 H2-2 와 같다: 관측·행동 간격 0.1 s 로 머리 흔들기 위상의 농도 변조(좌우 기울기)를 줄 것. 그때 (1) 첫 진입 팔이 냄새를 따르는지, (2) 등쪽/배쪽 굽힘 선택이 기울기 부호와 일치하는지(논문의 "작지만 유의한 정답 방향 증가")를 판정한다.

1. 좁은 통로(체폭 4배)의 모퉁이는 깊은 굽힘이 벽에 눌릴 때만 돌아가고, **굽힘의 등/배 방향이 곧 모퉁이 방향**이다. 배쪽만 있으면 오른쪽 모퉁이는 0/32, T-미로 첫 진입은 100 % 배쪽 팔.
2. 시간 이력 감각만으로는 교차점에서 두 팔을 구별할 수 없어 "한쪽 먼저 + 틀리면 후진 교정" 이 정보상 최선이고, 정책은 이 전략에 수렴한다(도달 1.00, 목표 팔 1.0, 잘못된 쪽 비용 8–38 s). 편향 없는 올바른 첫 선택(Gourgou 2021)에는 좌우 기울기 감각이 필요하다.
3. 실제 벌레의 편향 없음(DI ≈ 0)은 이 모델에서는 등쪽 깊은 굽힘(Nature Neurosci 2026: SMDD 방향, RIV 배쪽 편향)과 좌우 감각이 함께 있어야 재현된다. 예측: 좁은 T-미로에서 팔 선택은 교차점 통과 순간의 굽힘 방향이 결정하고, 등쪽 회전 결손 조건에서는 배쪽 팔 편향과 목표별 도달 시간 비대칭이 나타난다.
4. 모델 한계: 벽 접촉을 추진에 쓰는 실제 보행(Park 2008)이 없어 통로에서 느리고, 등/배 비용 비대칭이 없어 배쪽 선호를 설명하지 못한다.

산출물: `worm/body/rod2d.py`(벽·접촉), `worm/env/mazes.py`, `experiments/wormgym_maze_analyze.py`, `wormgym_weathervane.py`, `runs/wormgym/h5/` (모든 로그·분석·그림), ADR-017.

### H5-8 (사전 등록, 2026-09-05): 좌우 기울기 정보가 있으면 정책이 그것을 쓰는가
- H5-6·H5-7 의 해석("시간 이력만으로는 교차점에서 팔을 구별할 수 없다")을 직접 시험한다. 관측에 머리 좌/우 0.1 mm 지점의 로그 농도차 × 10 을 추가 (`--lateral`; 실제 벌레의 머리 흔들기 표본을 이상화한 것으로 원칙상 감각의 단순화이지 커넥톰 변경은 아니다).
- 학습: 평지 2.5 mm (60세대) → T-미로 (60세대). `runs/wormgym/h5/lateral/`.
- 판정: (1) 평지 풍향계 일치율 > 0.7, (2) T-미로 첫 진입 = 목표 팔 > 0.7, (3) RIV 펄스 굽힘 방향 = 소스 쪽 > 0.6. 셋 다 성립하면 "정보가 있으면 쓴다" → 실제 벌레의 편향 없는 선택은 좌우 감각의 산물이라는 주장이 완결된다. 불성립이면 학습 알고리즘·정책 표현의 한계로 본다.
- **평지 결과 (`lateral/flat`)**: 도달률 **0.988** (n=256), 중앙 **16.5 s** — 방향을 아는 오라클(0.895, 16.5 s)과 같은 속도. 정책 스윕: 변화 없음 구간에서 소스 왼쪽(lat +1) → SMDV 0.99 (등쪽 드라이브 상쇄 → 배쪽 굽힘 = 왼쪽), 소스 오른쪽(lat −1) → SMDV 0.02 (등쪽 굽힘 = 오른쪽); 즉 **굽힘 방향을 소스 쪽으로 고른다**. 연속 조향 지표(0.35)는 SMDD 가 상시 0.97 이고 SMDV 만 변조되는 구조를 잘못 읽은 것 → 실현된 펄스 부호 지표(`weathervane2.txt`)로 다시 판정.
- **실현 펄스 방향 = 소스 쪽 일치율 (`weathervane2.txt`, 128 에피소드)**: 좌우 정보 정책 **0.73** (펄스 5431개, 등쪽 2180 / 배쪽 3251 — **양방향 사용**), 좌우 정보 없는 ADR-017 정책 0.62 (등쪽 편중 4877 / 2083). **H5-8 판정 (3) 성립** (> 0.6). 에피소드 단위 재계산(E9, `experiments/wormgym_weathervane_episodes.py`): 0.73 ± 0.08 (128/128 에피소드 > 0.5) vs 0.61 ± 0.18, Mann–Whitney p 2.6e−8, d 0.85 — 펄스 비독립성을 감안해도 성립. 연속 조향 지표(1) 는 이 정책 구조(SMDD 상시 켜고 SMDV 로 변조)에 맞지 않아 폐기하고 실현 펄스 부호로 대체한다.
- 해석: 좌우 기울기 정보가 있으면 정책은 깊은 굽힘의 등/배 방향을 소스 쪽으로 고르며, 그 결과 오라클과 같은 속도로 직진한다. 실제 벌레의 "기울기 방향에 따라 등/배 회전을 선택, 정답 방향 비율의 작지만 유의한 증가"(Nature Neurosci 2026)가 모델에서 정량적으로 재현된 것이다 (모델 0.73 vs 우연 0.5; 정보 없으면 0.62). 좌우 정보 없는 정책의 0.62 는 시간 이력만으로도 약한 방향 편향이 가능함을 뜻한다 (머리 흔들기 위상과 농도 변화의 우연한 상관).
- T-미로 판정 (2) 는 `lateral/tmaze` 결과로.
- **T-미로 결과 (`lateral/tmaze`, `lateral/flat/side_stats_tmaze.txt`, 128 에피소드)**: 미로 학습 정책 — 도달 1.00, 목표 팔 1.0, 중앙 30.5 s, 첫 진입 **L 128 / R 0**, 교차점 부근 펄스 전부 배쪽(638/0), 오른쪽 목표 비용 7 s (30.5 vs 23.5). 미로 학습 없는 좌우 정보 평지 정책 — 교차점 부근 실현 펄스 방향 = 목표 팔 **0.80** (등쪽 3595 / 배쪽 1079; 오른쪽 목표에 등쪽을 쏜다)인데도 첫 진입 L 128 / R 0, 오른쪽 목표 도달 **0.00**. 즉 이 교차점에서 **등쪽(오른쪽) 굽힘은 기계적으로 오른쪽 팔 진입에 실패**하고, 학습은 그래서 등쪽을 버리고 "왼쪽 먼저 + 빠른 교정" 으로 간다. **H5-8 판정 (2) 불성립, (3) 평지에서 성립.**
- 새 가설 (H5-9): 줄기에서 벽 따라가기로 **오른쪽 벽에 붙어** 올라오기 때문에 오른쪽으로 말 공간이 없고 왼쪽으로만 말 수 있다 — 회전 가능 방향은 굽힘 방향뿐 아니라 **붙어 있는 벽의 쪽**이 정한다. 시험: 줄기 구간 머리 x 분포 (`stem_side.out`).
- **H5-9 시험 (`stem_side.out`, 64 에피소드)**: 교차점 직전 머리 x (통로 반폭 0.15, +는 오른쪽 벽 쪽): ADR-016 평지 정책 +0.069, ADR-017 평지 정책 +0.089 (줄기에서 오른쪽 벽 비율 0.72), 좌우 정보 정책은 목표 오른쪽이면 +0.043 / 왼쪽이면 −0.047 (줄기에서 이미 목표 쪽으로 기울어 있다). 즉 오른쪽 벽 붙기만으로는 오른쪽 회전 실패를 설명하지 못한다 — 목표 쪽으로 기울고 등쪽 펄스를 쏘는데도 오른쪽 팔 진입 0/128.
- 미해결: 이 교차점에서 등쪽 굽힘이 오른쪽 팔 진입으로 이어지지 않는 기계적 원인. 후보: (a) 펄스가 머리에서 꼬리로 전파하는 동안 머리가 이미 교차점 벽에 닿아 굽힘이 벽에 눌려 소멸, (b) 후진 단계의 배쪽 머리 편향(SMDV)이 다음 전진 방향을 왼쪽으로 고정, (c) 앞선 DOMEGA 스왑판이 양팔에 간 것은 펄스 부호가 블록마다 바뀌지 않고 고정됐기 때문 — ADR-017 규칙은 블록(50 ms)마다 dSMD 부호로 방향을 재평가하므로 펄스 도중 방향이 뒤집힐 수 있다 → **규칙 수정 후보: 펄스 방향은 발사 순간에 고정**. 다음 회차의 첫 실험으로 둔다.
- 후보 (c) 시험 (`lock_test.out`, `omega_lock=True`: 펄스 방향을 발사 순간에 고정): 좌우 정보 평지 정책 — 고정 유무와 무관하게 첫 진입 L 64 / R 0, 오른쪽 목표 0.00. **(c) 반증.** 남는 후보는 (a) 펄스가 교차점 벽에 눌려 소멸, (b) 후진 단계의 배쪽 머리 편향. 미로 학습된 좌우 정보 정책은 줄기에서 왼쪽 벽을 붙는다(0.64) — 왼쪽 회전에 맞춰 벽 쪽까지 바꿨다.
- **이번 회차 종료 (2026-09-06)**. 다음 회차 첫 실험: T 교차점에서 등쪽 펄스가 실패하는 기계적 원인 (a)/(b) 분리 — 교차점 통과 순간의 몸 형상·펄스 진행을 프레임 단위로 기록해 보고, 후진 단계의 SMDV 편향을 0 으로 절제한 변형과 비교.
