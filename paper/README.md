# Manuscript (LaTeX)

`main.tex` is self-contained (no `.bst` or class files needed) and compiles with pdfLaTeX.

Overleaf: upload `main.tex` and the `figures/` directory (or `worm-whisperer-overleaf.zip`), set the compiler to pdfLaTeX, and compile. The reference list is embedded, so one compile pass plus one more for cross-references suffices.

Content mirrors `../docs/PAPER_DRAFT.md` (v3). Figure sources: `../docs/figures/`, produced by `experiments/paper_figures.py`.
